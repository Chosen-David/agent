# MATH-29/30：二阶矩加权的双线性低秩

## 增加的能力与范围
补入math.weighted-bilinear-low-rank@1：独立q/k、有限正定非中心二阶矩、固定H时，将分数均方误差化为双侧加权Frobenius，并用既有SVD条目求有限秩最优A/B。关联输出几何/top-k前提，避免把K重建误差、分数、输出、端到端目标混为一谈。不是每条定理新增Skill，不改生产行为或SGLang。

新卡显示一般代数证明；CPU数值例子只核对有限实现。独立验收尚待回读；原始数据不凭生产者自报用于性能结论。

## 迁移与负结果
公开固定例：Sq=diag(.01,100)、Sk=diag(100,1)，同rank1下K-PCA分数MSE100、双侧解1。跨域传感器映射为独立载荷/模态与固定耦合H，数学结构相同；没有实际物理传感器实验。q=k的三点分布实际平方风险2，二阶矩乘积1，拒用独立因子化。奇异/不定输入拒用SPD接口；非零均值须使用非中心二阶矩。M一般不对称，不能冒充共同正交投影/单频FC融合。真实attention相关q/k只能先构造经验产品代理并核对实际paired风险，不直接修改生产。

2026-10-07核对Cornell作者讲义2025-10-15的Eckart–Young–Mirsky段落（来源支撑SVD，双侧概率化归为本条目推导）。RoLA最新可见v3、2026-09-21修订，定向读§4.1–4.4和§9.1，预印本/正式venue未核实；低秩非线性特征后旋转、相对位置结构不等于原dense softmax等价，也不等于任意频率可无损融合。SALS可见v1、2025-10-28，定向读§3/4.1/7；pre-RoPE选token、重建选项后加RoPE是可比较路线，其OS名称在§3.2实际定义为概率质量而非集合重合比例。作者观察的post-RoPE有效秩增加不是所有输入的定理。没有复现两论文模型/速度。来源/版本与采用/暂缓见research.json。
