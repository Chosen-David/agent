# MATH-33/34：有限菜单选择后的风险与期望预算

日期：2026-10-08（Asia/Shanghai；原文检索实际发生于UTC 2026-10-07）。基线main：`7e997b54348554553e287d3cf4069df791f69fb9`。本轮仅增加经过检查的知识入口与证据，不修改生产行为、SGLang或已有Skill。

## 真正增加的能力

`math.finite-menu-selection@1`将单候选Hoeffding界扩展到校准前冻结的有限候选族，再说明如何在同一校准集上选择而保留同时保证。固定M个有界损失、固定n个iid样本、置信失败概率δ时，每个候选的半径为`R_h sqrt(log(2M/δ)/(2n))`。所有候选可以共享样本、彼此相关；独立性要求针对样本单位。联合界给出同时有效区间，随后η近似经验最优的超额总体风险不超过`r_selected+r_oracle+η`。一般证明经过自然语言数学复核，不是形式化证明。

损失与有界成本联合认证需按2M个函数分配失败概率，对应`log(4M/δ)`。以成本上界筛出安全集合后，选中候选可认证总体**期望**成本不超过T。它不能认证每次运行的硬预算，也不能自动证明真实可行最优候选进入安全集合；后者需要相应成本余量。若集合为空，应报告无候选获认证。

学科索引更新probability-and-optimization与optimization；问题结构来自条目元数据finite-family/uniform-convergence/selection-bias/risk-control/expected-budget，经现有CLI按需检索。强依赖仅加载`math.hoeffding-bounded-mean@1`，未增加新的Skill。

## 对逐层indexer求解器的具体迁移

原对象是模型层参数和method组合；理论对象是冻结候选h及在独立校准文档上的有界损失/成本。推荐先用探索集产生少量**完整联合配置**，再冻结候选、指标、预算与样本单位，使用新的校准集认证，最后在未参与开发的数据上做端到端对照。公开LongBench任务被反复用于修订后不再是未见测试；固定benchmark也不自动构成目标总体的iid样本。

这里保留候选选择、共享校准样本和均值风险关系；没有把局部层误差等同于端到端质量。若L层分别有J_l档位，全联合配置最多有乘积ΠJ_l个，不能用和ΣJ_l的菜单规模认证任意联合配置的非可加e2e损失。只有实际证明局部目标/误差可以组合时，才能另作局部推导。校准后的搜索扩充菜单、重复使用文档内token作为独立样本，以及部署分布漂移都会破坏当前保证。

可证伪预测：在固定菜单、iid文档和预先确定范围成立时，独立重复校准中的同时越界频率应受δ控制；若模型e2e或成本超界，需要检查范围、样本依赖、菜单泄漏、分布变化及测量误差。此预测尚未做模型实测。跨域例子是传感器滤波档位选择：参数对应候选，独立重复测量对应样本，归一化失真对应有界损失；未做物理实验。

## 实际验证与成本

生产者`verify.py`公开开发样例含40组有限配置、28组精确二项分布配置和604次断言。确定性均值/成本用Fraction；其中一些估计值超出[0,1]，仅作为同时好事件下的代数检查，不声称是有界样本的实际经验均值；二项事件概率精确求和，log/sqrt阈值采用浮点并检查分离。反例包括：看完样本才构造的“单候选”记忆规则、全部复制同一随机变量、零范围、空安全集、分布漂移以及期望预算与单次超预算。

独立owner `/root/selection_verifier`阅读实际代码、输入和证明，采用70位Decimal阈值及另一种概率递推，核对28组配置的376个结果；另作16组完整序列枚举与127次风险检查。重跑raw字节一致；最小阈值分离约0.00290519。高精度一致不是实数形式化证书，数值样例也没有替代一般证明。独立验收绑定`manifest.json`及其实际代码、全检索语料摘要、原始数据、版本来源、指标和环境。

3个不提示定理名称的公开问题分别是配置海选、跨领域滤波和泄漏反例。人工抽取结构查询后，files/sqlite两后端6次搜索均将目标条目放在第一位。这只是结构检索检查，没有测量模型自动抽取前提、正确拒用或未见问题能力。
