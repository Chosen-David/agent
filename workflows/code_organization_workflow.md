# 代码组织工作流

[返回](../../README.md) · [技能入口](../plugins/research-assistant/skills/code-organization/SKILL.md)

## 适用

- 任务链收官后整理实验仓库（脚本→实验→结果映射丢失、命名时间线化、"不知道哪个对应哪个"）；
- 长期迭代仓库的周期性结构维护。

## 不适用

- 运行中的管线整理（等任务完成再动输出路径）；
- 代码逻辑重构（走实现优化工作流）；
- 用户明示不可修改的文件（如私人探索记录、论文设计文档）。

## 流程

1. **只读盘点**：枚举脚本/结果/文档，提取实验代号映射（头注释、输出路径、git log）。
2. **落 CODEMAP**：`实验代号 | 结论 | 脚本 | 数据 | 结果 JSON | 论文引用` 表格，增量更新。
3. **目录 README**：必要目录一段话功能 + 命名约定 + CODEMAP 链接。
4. **重组提案**：孤儿/重复/命名漂移清单 + 建议动作 + 风险 + 回滚方式，写提案文件等用户拍板；删除永远不自动执行。
5. **授权执行**：git mv 逐组提交、修复引用、最小验证。

## 输入

- 目标仓库路径（默认当前任务链仓库）；
- 可选：最近任务链清单（用于"活跃文件"判定）。

## 输出

- CODEMAP.md（增量）、目录 README 若干、reorg 提案文件、（授权后）移动 commit。

## 验收

见[执行与验收](../plugins/research-assistant/skills/code-organization/references/execution.md)：映射覆盖 ≥95%、移动项干跑通过、删除项 0 执行。

## 失败降级

映射不全时标 unknown/backlog，不猜；无 git 仓库时移动全部降级为提案。
