# 条件 Fano 与有限消息辨别容量

稳定 ID：`math.fano-message-budget@1`。有限标签分类定理及本文推导；非 LLM 性能结论。前置 `math.data-processing-task-sufficiency@1` 提供 Markov/DPI 与任务后验充分性；本条加入容量和错误概率的必要界。与 `math.softmax-barycenter-error@1` 的连续输出误差不同，分类错误不直接等同注意力输出偏差。

## 对象、假设与准确结论

Y∈{1,…,M} 为必须识别的标签；T 为消息，Z 为接收者已有的旁信息，所有 log 使用底2。先定义 Ŷ=g(T,Z)，Pₑ=P(Ŷ≠Y)。M≥2时：

H(Y|T,Z) ≤ h₂(Pₑ)+Pₑ log₂(M−1),

Pₑ ≥ max{0,[H(Y|Z)−I(Y;T|Z)−1]/log₂ M}.

第二式较弱，可能为零，不能解释为可达到零错误。随机解码器须满足 Ŷ ⟂ Y | (T,Z)，不能暗中使用与Y相关的随机种子。M=1时恒为零错误，禁止代入第二式除以零。M=2时第一式右端仅 h₂(Pₑ)。

若每个给定z的合法消息字母至多C种，则

I(Y;T|Z) ≤ H(T|Z) ≤ log₂ C.

更直接的计数界是

P(success) ≤ E_Z [Σ_{i=1}^{min(C,M)} p_(i)(Z)],

其中 p_(i)(z) 为按降序排列的 P(Y=y|Z=z)。均匀标签且Z不提供信息时成功率至多 min(1,C/M)。非均匀先验应使用最大的C个后验概率之和，不能机械套C/M。不同z的C若不同，应逐z使用C(z)，不能取平均字母数替代log平均。

固定B-bit消息有C≤2^B；固定n-token消息和有限词表大小V有C≤V^n。这是消息空间的上界，不能证明模型会用满容量，也不能证明自然语言质量与长度的关系。token预算性能需要实际分词器、协议、所有调用和模型测试。

## 核心证明与可复核推导

令E=1{Ŷ≠Y}。E由Y,Ŷ决定。熵链式法则给

H(Y|T,Z) ≤ H(E|T,Z)+H(Y|E,T,Z).

第一项≤h₂(Pₑ)，正确时第二项为0，错误时最多M−1种标签，所以≤Pₑ log₂(M−1)。随机解码可额外条件化独立随机变量U：H(Y|T,Z,U)=H(Y|T,Z)，然后同样证明；相关U不满足该等式。利用h₂≤1、log₂(M−1)≤log₂M及H(Y|T,Z)=H(Y|Z)−I(Y;T|Z)即得弱式。字母界来自熵最大值及条件互信息≤条件消息熵。

计数界：固定z，任何确定解码器至多输出C个不同标签；成功质量不超过这些标签后验概率之和。编码器即使直接知道Y也无法超过最大的C个概率之和，此时能达到该上界；编码器若仅有含噪X则通常不能达到。随机协议的线性期望目标可固定随机种子取极点，或逐消息把解码成功贡献界为最大后验贡献，不会优于确定极点；接收者的共享随机性作为Z并逐条件核验。以上是一般非形式化数学证明，有限数值核验不代替它。

## 正例、边界与误用反例

- 均匀8个分片标签、仅2种消息、无其他信息：成功率≤1/4；若接收者知道四组中的组号，每组两分片，两消息可完美选组内分片。旁信息改变了问题。
- p=(0.7,0.1,0.1,0.1)、两消息：最优成功率0.8，大于均匀公式0.5，拒绝忽略先验。
- 变长二元字符串“空串”“0”“1”都有长度≤1，但有3种可辨消息；长度/结束符可传信息。不能将最大长度1直接当作固定1-bit。若规定前缀码/固定格式，应重新计算合法字母与平均长度关系。
- 接收者可以工具检索原始ID时，工具返回是额外观察，不能只对压缩T的字母数宣称整个系统的失败下界。
- 连续控制量、自由文本质量、遗漏value引起的注意力误差不是本条的有限标签任务；须先定义离散决策/损失，否则拒绝Fano错误率结论。

## 问题结构与 Agent 迁移

先抽取：必须区分的对象Y、目标损失、可见消息T、接收者先验/缓存/检索Z、合法消息格式和支持数C。仅加载本条及DPI前置，记录ID与旁信息依据。消息过短的计数反证是对协议能力的限制，不是已测出的 Agent 失败率。

具体对应：任务链路由的8个分片ID→Y，发送者的两个控制符号→T，接收者任务清单/组号→Z。保留的是有限协议和辨别事件；自然语言摘要的“意义”并未映射成消息容量模型。预测：若固定协议确实只有两种可见状态且八标签均匀，无旁信息，就不可能超过1/4；添加真实四组组号后可达1。公开精确枚举验证此边界，不模拟LLM。候选设计为“紧凑计划＋完整待办ID清单/可验证检索引用”；尚未改生产，须同模型同工具同完整token预算测错误、ID覆盖、延迟与调用数。
