# 固定 value 的输出几何与局部 logits 敏感度

ID: `math.attention-output-geometry`；版本1。触发问题：两套权重或分数的误差大小相同，实际输出为何不同？先提取固定支持集、value、输出投影和实际下游映射；不加载整个知识库。

## 对象与准确结论

有限 n≥1，V∈R^{n×d} 的行是 v_i，固定 W∈R^{h×d}，Z=VWᵀ。α、β是同一集合上的概率向量（允许零），δ=β−α，z=Zᵀα、zhat=Zᵀβ。以下是经典线性代数与微分的可复核推导，不声称新定理或论文原创。

\[
\|\hat z-z\|_2^2=\delta^T C\delta,\qquad C=ZZ^T\succeq0.
\]

概率归一化给出1ᵀδ=0。对任意a∈R^h，把所有Z行减去a不改变输出差或上述二次型。因此应使用中心化 value 差异，不能以value均值大小决定敏感度。δ落在ker(Zᵀ)时，即使概率改变，输出仍不变。C通常只是半正定；不存在不带最小奇异值前提的反向误差界。

局部部分限定α=softmax(s)，s有限、温度已计入，V/W固定、支持集不变。J=diag(α)−ααᵀ，e是有限logits扰动：

\[
D z(s)[e]=Z^TJe=\sum_i\alpha_i(Z_i-z)(e_i-\alpha^Te),\quad
\|Dz[e]\|_2^2=e^TG e,\quad G=J C J\succeq0.
\]

G1=0；共同logits平移无影响。G取决于query的α、value和W，不等于K协方差，也不自动等于对角重要性。忽略非对角项会遗漏抵消/协同。

设D=max_ij‖Z_i−Z_j‖₂，w=max e−min e。对任意有限e都有：

\[
\|z(s+e)-z(s)-Z^TJe\|_2\le D w^2/8.
\]

这限制的是一阶输出近似的余项，不是端到端任务误差。硬mask造成−∞，不满足此局部定理；剪枝后β仍可用于第一条精确Gram恒等式，须实际重新归一化。若同时改变value，则另加\((Zhat-Z)^Tβ\)项，不能只算δ。

## 推导与来源范围

第一式展开‖Zᵀδ‖²即可；a项因1ᵀδ=0消失。对softmax逐项求导得∂α_i/∂s_j=α_i(1_{i=j}−α_j)，继而得J和G。令p(t)=softmax(s+te)、μ(t)=Σp_i e_i，沿路径有

\[
z''(t)=\sum_i p_i(t)(Z_i-z(t))(e_i-\mu(t))^2.
\]

z(t)是凸组合，所以‖Z_i−z(t)‖≤D。有限区间变量方差≤w²/4：由(E−m)(M−E)≥0得Var(E)≤(M−μ)(μ−m)≤(M−m)²/4。因此‖z''(t)‖≤Dw²/4，积分Taylor余项∫₀¹(1−t)z''(t)dt给Dw²/8。这里完整写出所需方差证明，没有暗用独立性。

经典参考：Petersen–Pedersen《The Matrix Cookbook》，2012-11-15版，§2.4.2 Eq.(81)、§2.4.4 Eqs.(96)–(98)，印刷页11–12，支持二次型/微分记法；上述attention专门公式由本卡直接推导，不能把它们归为教材原句。前置为矩阵转置乘法、链式微分与凸组合；`math.softmax-barycenter-error@1`提供非局部概率/剪枝界，`math.score-difference-bound`提供不同对象的排序导航。

## 正例、边界、误用反例

α=(1/3,1/3,1/3)、v=(0,1,100)、W=1。同为‖δ‖₂=√2·0.01，δ_A=(−.01,.01,0)使输出改变.01，δ_B=(−.01,0,.01)使输出改变1。相同概率误差不能确定输出质量。

所有value相同，或W把差异全部投影到零，C/G敏感度为零，概率MSE仍可非零。n=1时J=0。固定大共同value偏移不影响差；浮点大偏移仍可能导致消减误差，实数平移恒等式不免除数值审查。

对大扰动不能把G的局部二次损失当精确有限误差。模型后续非线性、不同query、不同生成轨迹改变α/V/W，旧G不能自动复用。负权重不满足凸组合余项证明；非归一化权重不满足共同value平移不变性。

## 迁移与可证伪设计

Indexer固定trace：完整与稀疏注意力权重对应α/β（剪枝项补零），value对应V，当前头输出投影对应W。NoPE、RoPE和混合模型均在位置变换完成后适用；不授权跨频率精确融合。固定索引字节预算、最终KV预算和trace，比较输出误差与eᵀGe、重合度/质量的关联，再用未参与选择的文档测试。G是离线诊断/训练目标候选；完整C有n²成本，不能默认部署。计算精确误差直接用Zᵀδ，O(nh)，无需形成C。

固定线性分类器ℓ_j=a_jᵀz+b_j，dense赢家c、真实margin γ_j=ℓ_c−ℓ_j>0。若已认证输出误差E，且每个j≠c满足‖a_c−a_j‖₂E<γ_j，则赢家保持；由柯西不等式逐对证明。只保证这个固定分类器/输入，不保证LLM生成序列或LongBench精度。

跨域：非负归一化配料质量分数α/β、组分浓度V、固定线性传感器W，同样的Gram几何精确给浓度差平方，单位为浓度²；非线性化学反应、体积收缩、未归一化质量直接拒用。Agent文本消息不是固定线性混合，不将此式作为通信省token保证。
