# 奇异支持下的双线性低秩分数近似

稳定 ID：math.singular-support-bilinear-low-rank；版本1；核查日期2026-10-08。

## 触发问题与数学对象

校准 query/key 的二阶矩秩亏，无法全空间 whitening inverse；应在明确的有效支持内求解，而不是把奇异性藏进逆矩阵。以下推广是项目自己的推导，使用经典截断 SVD 和 Moore–Penrose 伪逆，不声称新原创定理。

q∈R^m、k∈R^n 独立，有限**非中心二阶矩** Sq=E[qqᵀ]≥0、Sk=E[kkᵀ]≥0；H∈R^(m×n)固定。目标是 J(M)=E[(qᵀ(H−M)k)²]，rank(M)≤r，r为0至min(m,n)的整数。q/k不必高斯或零均值。负特征值不符合二阶矩模型；中心协方差、真实 paired 分布、softmax、输出误差不是本目标。

L=Sq^(1/2)、R=Sk^(1/2)是对称 PSD 平方根，L⁺、R⁺取**精确非零**特征值的倒数；Pq=L L⁺、Pk=R⁺ R是正交支持投影。C=L H R。零支持与空有效特征合法。

## 准确结论与可复核推导

独立性和有限二阶矩给出 J(M)=tr((H−M)Sk(H−M)ᵀSq)=||L(H−M)R||F²。可先对k条件期望，再对q取迹；若同一文档成对样本相关，条件二阶矩依q而变，不能代换。

C=Pq C Pk。选取 C 的秩≤r截断 SVD Cr，使其非零奇异向量留在这两个支持中，故 Pq Cr Pk=Cr。零奇异值项系数为0，不强迫任意零向量满足支持。重复奇异值允许不同的 Cr。

规范回提升：M0=L⁺ Cr R⁺，rank(M0)≤r。因为 L M0 R=Pq Cr Pk=Cr，它达到

min_rank(M)≤r J(M)=Σ_(j>r) σj(C)²。

下界来自任意 X=L M R的rank≤r与经典Eckart–Young–Mirsky；上界由上面的支持内回提升达到。奇异情况下 X 不遍历全部 rank≤r 矩阵；不能复用正定卡的全空间双射论证。只需存在支持内的最优 Cr。

对一个**固定 Cr**，全部回提升满足 M=M0+N、L N R=0（等价 Pq N Pk=0）。M0=Pq M0 Pk，因此 Frobenius 内积〈M0,N〉=0，||M||F²=||M0||F²+||N||F²；M0是该固定Cr的唯一最小Frobenius范数回提升。若要求仍属于原秩预算，必须另外检查 rank(M0+N)≤r。不是所有不可见 N 都可加，也未证明不同 tied Cr 中哪一个回提升最小范数。

null(Sq) 中任意v满足E(vᵀq)²=0，故vᵀq=0几乎处处；有限维零空间基给 q=Pq q 几乎处处，k同理。于是不可见 N 在本分布下逐点几乎处处不改变分数，但这不保证新分布支持仍相同。

Cr=Ur Dr Vrᵀ时可用 A=Dr^(1/2)UrᵀL⁺、B=Dr^(1/2)VrᵀR⁺，M0=AᵀB，得到(Aq)ᵀ(Bk)；r=0用零矩阵/空特征。当r≥rank(C)时风险0，即使H全秩也可能成立；不能推成任意q/k无损。

## 正例、边界与跨领域迁移

线性传感器：a=(1,2,0)、b=(1,0,3)，q=u a为无量纲可编程增益，k=v b为电压(V)，u∈{−1,1}、v∈{−2,2}独立均匀。H=diag(2,5,7)以电导(S)计，分数为电流(A)，qᵀHk=2uv。两个二阶矩均rank1。

r=1可取M0=a bᵀ/25（单位S），qᵀM0k=2uv，均方误差0 A²；||M0||F²=2/25 S²。取c=(2,−1,0)，N=c bᵀ则aᵀc=0，M0+N仍rank1、分数不变，范数平方为1252/25 S²。不可见自由度存在，规范解更小。反过来任意N如独立第三坐标可能增秩，必须核对。

支持漂移：q=k=(0,1,0)（分别用gain/V单位），原分数5 A而M0给0，缺口5 A。校准零误差不代表未知工况无损。传感器仅合成线性映射验证，未测真实物理系统。

## 误用反例与拒用

- **相关分布**：q=k∈{−1,0,1}，概率{1/4,1/2,1/4}，H=1、M=0。真实风险1/2；两侧二阶矩乘积仅1/4。不能把“paired样本”自动当独立。
- **中心化误替**：q≡2、k≡3，H=1、M=0，风险36，而中心协方差都0。
- **ridge改变目标**：Sq=Sk=diag(1,0)、H=diag(1,10)、r=1。支持目标选diag(1,0)，风险0。加λ=1后加权C=diag(2,10)，截断并反变换选diag(0,10)，原风险1。ridge可能有稳定性价值，但不是精确优化原风险；非本轮推荐生产默认。
- **tiny≠zero**：q=(0,±10⁻⁶)、k=(±1,0)独立，H₂₁=10⁶。Sq唯一非零值10⁻¹²，原分数±1、丢弃方向的真实风险1。单看小特征值不能证明该方向无用。
- 伪逆放大：平方根特征值10⁻⁶时，该方向whitened扰动10⁻¹²回提升可变10⁻⁶。数值阈值是新的截断模型，不是精确秩证书；同时记录目标变化和实际误差。

实际原型使用**已声明的正交支持基**与严格正尺度，不根据容差声称识别真实支持。NaN/Inf、错形状、非正尺度、非正交基、非法rank、非实输入拒用。输入采样无足够证据时，只能给条件式结果。

## 对 indexer、NoPE/RoPE 与知识入口的意义

原对象q/k/H对应投影代理的分数；经验 q×k 笛卡尔积可以定义合法独立乘积分布，因此该**有限代理目标**可精确成立。真实因果paired风险、长度分布和文档留出必须另测。保留所用知识ID、版本、哈希与独立假设，不把所有条目装进上下文。

NoPE可直接对固定内容分数建模；RoPE应明确使用实际post-RoPE向量或每个位置差对应的H，位置改变可能改变支持。NoPE+RoPE共同压缩不意味着潜在两维继承代表FC频率；跨频率 intertwining 另有条件。这里不修改旋转结构，不认证实数投影的浮点输出，也不保证top-k、V/W输出或e2e最优。

最小可证伪预测：在相同索引维数下，支持内加权解的**冻结经验乘积MSE**等于C的尾和，且不差于可行rank同预算基线；若实际成对风险或留出排序变坏，则拒绝宣称质量改进。最终保留全KV时新增潜在key仍是额外缓存，投影/校准/数值秩评估成本需计入。无实际收益只保留知识与负结果，不接生产。
