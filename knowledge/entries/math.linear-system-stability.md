# 线性系统的可靠性

## 触发与结论
求解 Ax=b，即使残差很小，也先检查问题本身的敏感性。令 κ(A)=‖A‖‖A⁻¹‖、r=A x_hat−b，则
‖x_hat−x‖/‖x‖ ≤ κ(A) ‖r‖/‖b‖。
若 (A+E)(x+Δx)=b+e，令 a=‖E‖/‖A‖、β=‖e‖/‖b‖，在 κ(A)a<1 时，
‖Δx‖/‖x‖ ≤ κ(A)(a+β)/(1−κ(A)a)。

## 推导
残差式由 x_hat−x=A⁻¹r 与 ‖b‖≤‖A‖‖x‖ 得到。有限扰动用
(I+A⁻¹E)Δx=A⁻¹(e−Ex)。当 ‖A⁻¹E‖≤κa<1 时，Neumann 级数使逆的范数至多 1/(1−κa)，再取范数。
这补全来源省略的有限扰动代数；不是形式化证明。

## 可算例子与反例
A=diag(1,0.001)，x=(1,1)，b=(1,0.001)。x_hat=(1,2) 的残差范数只有 0.001，但解的相对误差约 0.707；κ₂(A)=1000。
κ=10、a=0.01、β=0.002 时有限界为 0.133333…；一阶表达为 0.12，后者不能替代前者作严格保证。
A 奇异、b=0 或 κa≥1 时不能使用本条相对界；不代表每个实际输入都必然失败。

## 任务映射
Agent 在比较低精度求解、压缩、近似缓存或模型参数恢复时，先报告残差、范数及条件估计。条件数是问题性质，后向稳定性是算法性质；两者不能互换。该界没有证明速度、所有分量相对精度或模型最终精度。
