# 矩阵秩、秩分解与左右等价

稳定 ID：math.matrix-rank-factorization；语义版本1；核查日期2026-10-07。

## 对象、符号与前提
A∈F^{m×n}，精确域算术，rank A=r；左右换基可以独立。

## 经典结论
A=CR，C∈F^{m×r} 满列秩、R∈F^{r×n} 满行秩；存在可逆 P,Q 使 PAQ 为矩形 diag(I_r,0)。行秩=列秩；左右等价由秩完全分类。

## 证明思路与可复核推导
选 A 的 r 个基列组成 C；每列在 C 中的唯一坐标组成 R，被选基列给 R 内一个 I_r。C 为单射、R 为满射，故二者秩均r。分别选核、像的基得到标准矩阵；行秩由 R 的行独立及 C 具左逆推出。

## 正例与边界
A=[[1,2,3],[2,4,6]]，C=(1,2)^T，R=(1,2,3)，r=1，存储从6标量到5标量。A=0 用零列 C、零行 R。

## 误用反例与拒用条件
精确低秩不等于近似低秩或运行一定更快；diag(1,10⁻¹²) 精确秩2但数值秩随容差变化。rank 相等只给左右等价，不给相似或正交等价。
