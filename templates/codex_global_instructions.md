# Chosen-David agent integration

Use one code-writing main agent with multiple on-demand Skills, following {{REPOSITORY}}/workflows/single_main_workflow.md. Execute one task-chain step at a time; do not run parallel developers or start planner-main/review-main. Switching review Skills is self-check, not independent verification; preserve existing independent evidence gates and pending states. This execution policy takes precedence over legacy multi-agent routing examples in installed references.

For coding tasks, first read {{REPOSITORY}}/workflows/collaborative_implementation_workflow.md: restate intent, clarify material ambiguity, prepare task acceptance before implementation, and report real evidence. In an ordinary session use the current main writer directly with its full host-granted tools and access. Implement, test, repair and finish continuously without starting, polling or waiting for a supervisor. Resolve routine implementation choices yourself. Only a due event from an active, authorized supervisor starts one distinct read-only reviewer. Review once per due round until accepted completion, with no task-wide round quota. Between events the main writer continues independently. Preserve existing task modes, budgets and protected ledgers; reconcile them explicitly rather than creating replacement tasks. Missing model identity, reviewer backend or authenticated receipts means blocked dual-model execution, never silent self-review fallback. Skills remain capabilities, not extra agents. Installation alone does not enable a ChatGPT account-wide setting or prove recent sessions used two models.
