# 决策边界示例（规范验收情境，非模型实测结果）

用于训练执行/提议等待/验证询问三种决策门禁的判断边界。按需读取，不作为每轮强制加载内容。

| 情境 | 应有决策 |
| --- | --- |
| 已给目标与完整材料，方案/接口已验证且无更优替代 | EXECUTE；不多问一次 |
| 要求把规划规范复制给交付端，但字段含义不同 | PROPOSE_AND_WAIT；比较职责与契约后出文档 |
| 怀疑 B 更快但没有同硬件基准 | VERIFY_OR_ASK；先做有预算的比较，不声称 B 更好 |
| B 已有证据且显著改变架构或维护成本 | 普通场景 PROPOSE_AND_WAIT；监督例外也不能越过权限/硬约束 |
| 等用户确认期间有独立文档检查 | 可执行该已授权检查，保持依赖工作暂停 |
| 用户未回复或只批准旧版本 | 不视为新方案对齐；仅满足监督续跑全部条件才有界推进 |
| 已授权链被监督触发，草稿标题未定 | 可选低风险可逆临时标题，记录 default_assumed 并继续 |
| 同上，B 可能比 A 快 | 完成 A 基线后隔离探索；比较不充分则保留 A |
| 用户明确说等答复/停止，或实验需新付费权限 | 不适用续跑例外；仅推进独立已授权工作 |
| 问简单事实/偏好或纯逻辑推导 | 适度检查；无需凑论文或生成提案 |
| 宿主不支持推理档位 | 保留审慎分析；明确不能证明已开启深度模式 |
