# ITER-10ROUNDS-20261023: 手动触发10轮不间断优化

## Plan

连续执行10轮 agent 库迭代优化，每轮独立发现、实现、测试、推main。
每轮目标：发现一个性能/token/效率问题 → 修复 → 验证 → 推main → 记录。

**优化方向候选池**（按影响排序）：
1. research-assistant skill 精简（58文件/571KB，最大skill）
2. orchestrator.md 瘦身（14.6K chars 系统提示每轮注入）
3. agent smoke test — 测全部16个agent找token浪费
4. setup.py agent_text() 进一步优化
5. templates/config 未使用文件清理
6. prompt_context.py 装配效率
7. 跨会话记忆对齐工具
8. scripts/ 未使用脚本清理
9. references 去重后的加载路径优化
10. 安装器 portable 模式磁盘开销
