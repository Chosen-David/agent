消除全 active 场景对无关内容和依赖的读取。不改变记忆/API、模型、外部服务
或跨请求缓存；不是模型 KV 接入。用户授权测试验收后直接推 main。

契约：API 合法记录完整返回、排序、freshness、接受/修正不变。针对 scope/
document JSON 的独立损坏，保留 JSON 解码早于成员错误；缺文档表、缺依赖表、
空库、类型 fallback 单独验收。不承诺任意手工损坏 SQLite schema/content

可能不再触发其非法 UTF-8 读取错误。不能把这些情况计作已通过的全面差分。

双方同 DB SHA256，各 warmup 一次，完整 list 路径 wall ms、完整返回比较。
两主场景：2000条全 active、scope每100条匹配1条，内容128B/8192B；各需下降≥25%。
五控制：2000全 active/全匹配、2000全 active/无 scope、8条全匹配、2000混合状态
scope稀疏、2000混合状态无scope；每项退化≤15%。主测与独立测串行，阈值不变。
最多2版候选、不超过30分钟本地CPU验证，无新增付费资源或外部请求。
