## Plan

目标版本 v1：按用户最新指令，将 Chosen-David/agent 的持续优化重点转为 Agent 记忆及相关 KV cache 存储。允许实现、回归、研究文档及验证后直接推送 main；其他仓库不在本任务范围。

依赖链：最新 main / 人类指南 / 既有结果检索 → 至少十篇原始论文的方法与实验核对 → 仓库真实入口定位 → 有界候选和修前基线 → 独立代码与数据核验 → 最终串行回归 → 发布及远端读回。主执行者独占任务文件；memory_scope_review 独立复核，不修改实现。手动宿主执行，不宣称已部署受管 DAG、ReviewSession 或后台监督器。

第一阶段复用 CO-017 的状态先筛选候选：保持完整记忆对象、排序、scope 精确成员语义及修正/依赖规则，减少无关历史的内容与依赖加载。预定门槛：历史密集场景中位耗时降低至少 25%，小库/全 active 控制场景退化不超过 15%。固定 21 对全入口本地测量，完整返回一致后才可接受。研究不能把 SQLite 收益解释为模型 KV、问答质量或 token 收益。

后续：确认实际模型服务及可用缓存接口，再做精确 prefix KV 接入与真实任务质量/TTFT 对照；缺后端只阻塞该部分。来源、版本、租户及失效依赖必须纳入缓存身份；压缩和非 prefix 复用另行验收。

证据：[研究与路线](../../results/memory-storage-20261015/research.md)、[实施报告](../../results/memory-storage-20261015/report.md)、[独立核验](../../results/memory-storage-20261015/independent-review.md)。保留所有失败，不改旧实验。
