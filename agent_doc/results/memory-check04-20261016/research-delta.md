## LightMem（2510.18866v1）

原文：https://arxiv.org/html/2510.18866v1 ，查阅日期2026-10-16。
覆盖 §3.1–3.3、§4.1–4.6、§6、B.1–B.3、C.1–C.2 的相关方法/评测。
方法组合输入压缩、主题边界、阈值批量摘要与离线更新队列；在线增量追加，
避免实时错误删除。对本库可借鉴的是保留原始证据、区分在线和离线成本。
不能直接用生成式摘要或低热度淘汰替换权威账本及其依赖失效检查。
§4.1 明确效率分析不含后续检索和问答；离线更新应计入建设总成本。
§6 将预计算 KV 用于离线更新列为未来工作，不能视为本文已验证的 KV 加速。
附录按类别结果有显著差异；C.1 五个压缩失败样本仍按错误计分。
当前不接入其模型流水线；恢复条件是实际模型后端、固定质量/修正集及建设到
查询的完整成本对照。本次只采用其评测边界启示，没有复用其论文数值。

## Memory OS of AI Agent（2506.06326v1）

原文：https://arxiv.org/html/2506.06326v1 ，查阅日期2026-10-16。
覆盖 §2.2、§3.1–3.5、§4.1–4.5 的方法、配置、主表和消融。
STM 对话页经 FIFO 进入按主题组织的 MTM，热度控制迁移和淘汰；先选主题段，
再选段内对话页，另从长期人格存储取信息。这里的分页是逻辑记忆组织，不能
等同于模型 KV 物理页缓存。可借鉴候选路由与内容读取分离，但语义摘要、
热度淘汰和 top-k 会改变选集，不可据此省略本库精确来源校验。
GVD 使用模型评判，LoCoMo 使用文本指标；表3报告调用/召回token，并未提供
可直接迁移到本库的完整 wall/峰值内存结果。表2区分引用 A-Mem 和作者重实现，
比较不能混用。现阶段不引入服务/embedding 依赖；待真实检索质量基准后评估。

## 当前实现决策

保留完整持久账本、逐次新鲜度检查和返回内容；只缩短不返回祖先内容的驻留时间。
以完整 `check()` 的 traced Python 峰值为主指标，另测未开启 tracing 的 wall；
无摘要近似、无跨调用缓存。旧 ResultStore 搜索为部分扫描（60条读失败），只复用
方法背景，不复用旧收益。知识搜索返回 QLoRA/HNSW 条目，与本次 SQLite DFS
不匹配，拒绝作为算法适用性证据。
