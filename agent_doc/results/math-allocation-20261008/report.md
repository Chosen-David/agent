# 离散逐层预算分配：MATH-31/32

本轮新增 `math.discrete-budget-allocation@1`：固定有限配置表、可加整数成本与损失下的精确动态规划，弱对偶下界与可行解上界，以及不被λ加权和选中的Pareto档位反例。这让主AI能够区别“代理优化已经精确求解”与“端到端模型已经改善”。没有改动SGLang、生产求解器、常驻Prompt或通信runtime。

## 新增推导与迁移

一般结论有显式归纳证明和已发布 `math.dual-certificates@1` 前提，不依赖数值例子证明。一个菜单(成本,损失)=(0,5),(2,4),(3,0)，预算2时最优为中间项损失4，但任何非负λ都不选择它；最优弱对偶值为5/3。因此仅扫λ或删除凸包外的未支配项可能漏掉精确整数最优。成本向上舍入/预算向下舍入只保证可行，不保证保留原问题最优。

你的逐层α/β/γ和method可以作为组内菜单，读取字节或操作数作为统一成本、固定trace的局部误差作为冻结代理。前4层Full可固定为单选项。DP检查的是该代理；真实层间互补、稀疏状态漂移、PP makespan或缓存竞争会破坏可加假设。公开耦合反例表明代理最优可比联合损失最优差。跨领域编码通道的比特/总失真分配保留相同离散结构；物理实验未运行。Agent通信/token分配仅是有前提的候选，重试和内容依赖使固定成本菜单失效。

## 实际验证和成本

公开CPU开发样例：28个菜单实例，364个预算案例（237可行、127不可行），64个精确有理数舍入案例，2,052项有限断言。整数/Fraction算术；DP与完全组合穷举一致，含空组、零成本、重复档位、不可行预算、负有限损失、对偶下界和耦合拒用。计时0.070692449秒仅本机生成/检查窗口，没有warmup、速度对比或性能结论。

独立上下文 `/root/allocation_verifier` 重读代码/配置/推导，重跑raw字节相同；另用稀疏精确成本状态和穷举检查880个独立种子案例。最终接受范围和文件hash见 independent/validation.json 与 review.md。非Lean形式化验证；有限数据不代替一般证明。

三个不提示定理名称的公开自然问题，先人工抽取结构，再两种实际检索后端；6次结构查询均首项返回新条目。领域optimization已显式指定，不冒充自动语义抽取或模型检索能力。案例公开且用于开发，不再是未见测试；holdout尚未执行，不伪造未见题。数学前提拒用为人工核对，不是模型实测。

知识回归74/74通过，插件同步/结构/引用校验通过；只修改一条知识及维护/证据，不运行无关全程序回归。完整两个show输出（含强依赖）编码4,943 cl100k_base tokens；不是宿主tokenizer、收费/主AI实耗或省token实测。检索CLI 9次=1index+6search+2show；额外检查、测试、网页与宿主调用另计，宿主总tokens未知，真实模型A/B调用0。知识用量、实际查询和SHA见knowledge-usage.json、cost.json、retrieval-corpus.json。
