# 奇异支持下的分数压缩_by_gpt

本轮补齐已有正定加权低秩知识的奇异边界。`math.singular-support-bilinear-low-rank@1` 在独立q/k、有限非中心二阶矩、精确指定支持及固定分数MSE目标下，以支持内截断SVD和伪逆回提升构造最优解。对固定加权目标的规范lift可证明唯一最小Frobenius范数；不同tied子空间和不可见自由度仍须核对rank预算。

## 对实际任务增加什么

主AI可识别“校准二阶矩不可逆”并选择支持模型，而不盲用原正定卡或加ridge后声称原目标最优。输入中心化、成对相关、数值阈值、样本支持和真实支持分别核对。新的知识ID通过既有model-with-knowledge入口与文件/SQLite检索接入，无新增Skill或生产行为变化。

原indexer对象为q/k/H与其低维双投影。有限校准q×k笛卡尔积定义严格经验乘积分布；真实paired风险和e2e不是这个代理。NoPE可建固定分数目标，RoPE需核对post-RoPE支持与位置分布；融合出的维度不自动继承单频FC。没有真实模型数据，不能把此条件式数学扩展写成indexer质量提升。

传感器迁移：增益无量纲、电压V、H/M电导S，分数电流A、风险A²。冗余三通道数据的rank1规范表示保留合成响应；换到未观测支持就出现5 A误差。这个负例阻止从校准零误差推断任意工况无损。

## 开发验证、成本和失败保留

72组Fraction精确有限分布风险恒等式/对角rank预算闭式解，另有非对角rank1候选对照；48组浮点非坐标支持/零支持/SVD与规范lift检查，1e-9缩放容差。修复版17/48组有正尾和；最大风险尾和绝对差约2.28e-13、最大lift残差约1.82e-14，均为有限输入的数值观测，不替代一般证明。15个非法/数值范围/显式注入SVD失败拒绝检查通过。

可证伪反例：相关样本真实风险1/2而独立代理1/4；中心化误替得0而真实36；ridge选错原支持目标；10⁻¹²二阶矩方向仍可贡献风险1。结论是“小特征值就不重要”和“ridge无损保持原目标”不成立。

三条没有定理名称的公开结构查询，在文件/SQLite共6次都命中正确ID。按需加载新卡及两张强前提，9422字符，预算18000字符。字符/字节不等于模型token；没有token节省、模型检索或拒用能力实测。
