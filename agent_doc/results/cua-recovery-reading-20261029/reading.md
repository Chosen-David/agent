## Method and construction

§3 separates persistent machine state, partial observations and native action history. A task passes only when all rubric criteria pass; weighted rubric partial credit and explicit error awareness are separate. Root cause is the earliest un-undone action identified against a solvable previous state, not an invalid-tool-call detector. Error horizon te−tr is first explicit evidence delay; takeover depth c−tr is inherited action count. Deterministic replay is conditional on disabled update/notification factors and verified recorded-state matching, not a general production replay guarantee.
