**Mechanism (§3).** Raw completed interactions remain the persistent source. Each decision selects relation type, temporal range, outcome filter and granularity; an event extractor normalizes selected raw interactions, rule validation filters unsupported updates, a composer/renderer builds a temporary image, and the frozen task policy chooses an action. Only executed interactions are appended; descriptors/images are discarded. Four relation types are TemporalTrace, ActionEffect, EntityState, DependencyChain; three ranges, four outcome selections and three detail levels form144 joint actions. DependencyChain anchors the latest event and uses shared entities/state keys/time proximity: it provides local cues, not complete causal/task dependency closure. Deterministic composition/rendering does not make the model-based extractor sound or the selected view complete; persistent recoverability is distinct from retaining all necessary evidence in this decision.

**Learning and interfaces (§3.3/A.2–A.3).** FrozenMiniLM encodes current state text and goal, each truncated to256tokens; local/global numerical descriptors use K8/M64 events. Four512dim projected tokens plusCLS pass a four-layer/eight-head Transformer, then three residual MLP blocks predict the joint144way distribution. The optional CLIP embedding is not used on the stated encode path. K8/M64 are descriptor horizons, not the selectable evidence window lengths. Action-conditioned teacher soft labels initialize encoder+head by KL; the teacher sees reference next actions offline, not at inference, and judges specifications rather than rendered views. GRPO uses trajectory-group relative returns (zeroadvantage for nearzero variance), fixed SFT reference KL and optional entropy; all decisions in a trajectory share advantage. Online ALFWorld/ALFRED training differs from offline Mind2Web replay. GRPO updates only head/output while encoder, task model, extractor and construction stay fixed. Table2 records training seed7, SFT50/20/50epochs and different rollout/replay settings; this is not a repeated-evaluation uncertainty report.
