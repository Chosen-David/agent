# guide：人类目标、编排意见与硬约束

本目录存放人类发布的项目目标、优先级、架构约定、禁止事项和验收要求。规范入口是 [GUIDE.md](GUIDE.md)，其他已确认来自人类的指导文件也应按适用范围读取。

在当前用户明确决定与宿主权限范围内，已核实的人工指南是最高项目规划依据。AI 的方案、记忆、其他 AI 的建议和既有 TASK 都应据此调整；不能为了方便实现自行降低要求或省略任务。

AI 对指南的处理责任：

1. 开始、恢复或接到指南更新时，阅读当前项目的指南，确认来源、版本和适用范围。
2. 将每项适用要求落实到 [task/TASK.md](../task/TASK.md) 的稳定任务 ID，以及详情中的方法、依赖、优先级和验收标准。
3. 对要求逐项给出需要的回应：怎样落实、当前结果与证据、尚未完成的部分；受阻时说清原因、缺少的条件和下一步。不能只回答其中容易完成的部分。
4. 发现要求矛盾、事实有误或执行条件不足时，明确说明，并把调整建议放进 [advice](../advice/README.md)；未获新决定前保留原要求及相关阻塞状态。
5. 指南发生实质变化时，重新核对计划、交接与旧证据的有效性；不静默改写旧记录以假装符合新要求。

人类维护和发布指南；AI 日常只读，不创建、编辑、删除、移动本目录文件。需要改指南时先提交建议，不能从 advice 自动生成或覆盖指南。

本 README 仅解释目录职责，由 AI 按用户 2026-10-08 的明确要求一次性创建；它不填写具体项目需求，不表示 GUIDE.md 已具备内容，也不授予后续写入权限。GUIDE.md 原文保持不变。
