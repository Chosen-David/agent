## 增加的数学能力

有限非中心二阶矩、Caa正定时，B=Cba Caa^(-1)为唯一无截距线性重建最优；残差矩S=Cbb−Cba Caa^(-1)Cab。任意T的残差矩等于S+(T−B)Caa(T−B)ᵀ，后项PSD。score=(u+Bᵀv)ᵀa+vᵀe。这些统计/score结论为本项目可复核推导，经典Schur基础来自Higham作者文（2023-06-01，显示更新06-06）：https://nhigham.com/2023/06/01/what-is-the-schur-complement-of-a-matrix/ 。

可拒绝的误用：S不等于一般条件协方差；线性正交不等于独立；真实paired query/key下重建最优未必score最优；pre-RoPE跨频率预测必须交织，内容可预测不等于旋转后仍可预测。NoPE、仅RoPE、混合三类对应关系见知识正文。

## 实际检查与负结果

- 25个精确公开开发案例（5种有限分布×5个预测矩阵）：非中心正规方程、Schur残差、PSD损失差、score折入及独立query风险等式；标量/矩阵、零残差、非线性、奇异与旋转边界另查。
- 成对反例中重建最优的keyMSE为1，另一个方案为2；真实scoreMSE却为1/2和0。不能仅优化重建或把它直接称注意力质量改进。
- 传感器合成迁移保持电压/电导量纲：遗漏电流MSE为45 A²，线性预测后9 A²；工况反转使原预测电压MSE为16 V²。没有硬件测量。
- 文件词法/SQLite各3个非定理名查询，共6次目标命中；含跨域与误用。目标和强前提共3条，11719字符；不是token计量。当前定向回归53项通过，镜像同步通过。

首次执行数学断言后，写JSON因tuple内Fraction序列化失败；失败代码/日志保留在v1目录。修复只加tuple递归，v2经新的真实计划审核后重跑。随后修正证据引用路径并重跑检索/相关回归，旧输出亦保留。测试脚本只用于固定、形状正确的有限fixtures，不是支持任意输入的生产回归API。
