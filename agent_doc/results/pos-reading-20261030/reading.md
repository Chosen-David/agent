## Method as actually read

§3 represents B=(world estimate, fixed goal, epistemic gaps, achievement gaps). World estimate uses task-relevant entities/states/relations with provenance/confidence/evidence where available. Active gap focuses action while broader belief remains. Structured natural language is an approximation inspired by POMDP belief; the paper does not prove it equals a Bayesian posterior or is a sufficient statistic. Self-declared confidence is not independently calibrated evidence.

Candidate belief update is generated by task agent; Sentinel audits additions/changes for internal conflict and disagreement with observations, then task agent evaluates feedback/revises and commits. All LLM components use the same evaluated backbone, temperature0. This is an extra model-mediated consistency procedure, not a trusted independent scientific acceptance adapter, user correction authentication or automatic discovery of every hidden dependency.

Progress for diagnosis uses half L1 confidence change aboveepsilon; execution progress is Sentinel-labelled active-gap reduction/information/plausible goal advance. Neither inherently certifies correct final outcome: confident oscillation may change magnitude, label/semantic matching depends on model judgments. Window health combines persistent initially unresolved gaps with max(stagnation,recurrence), H=1−max_X[P_X max(S,R)]. Empty initialgapset getsP=0. World-state distance averages Jaccard distances across aligned Entity/State/Relation sets projected to the active gap. Recurrence is the maximum over candidate lags of the fraction of state pairs whose distance is at most epsilon_W. A/B clarify the algorithm below; do not infer correctness from the formula alone.

Trapping pattern classifier uses ordered Static(full world state locally unchanged), thenCycle(recurrence with dominantlag>1), thenDrift(active-gap projection unchanged). Pattern escape constraints combine epistemic newdiscriminative evidence or achievement task-relevant statechange. Active gap remains fixed during recovery; constraints released when health exceeds threshold. These are inference-time instructions, not permission, effect rollback, task-budget refund, safe side-effect replay or persistence guarantees. General cycles/stalls could matter to current supervision, but no actual repository defect or beneficial transfer established.
