# application.stationarity-defect-amplification@1 — 近似定常权重与加权放大界

版本1，2026-10-14。经典有限维知识的任务级推导，复用 model-with-knowledge 和 math.cauchy-schwarz@1；不是新颖性主张或已发布canonical定理卡。

## 对象、假设与准确结论

固定有限n≥1，实B≥0、B1=1，严格正概率列π（π_i>0、Σπ_i=1），实函数/槽位特征列f，更新Bf。**本条不要求π定常**。概率列本身更新用Bᵀ，不与函数方向混淆。定义q=Bᵀπ、r=q−π、Dπ=diagπ、||f||π²=Σπ_if_i²。

定义ρ=max_j q_j/π_j=1+max_j r_j/π_j。则

||Bf||π² ≤ Σ_j q_j f_j² ≤ ρ||f||π²，故 ||B||π≤√ρ。

因为Σq=Σπ=1，ρ≥1；ρ=1当且仅当q=π。这个上界认证并不一般等于真实算子范数；不能从ρ>1断言给定输入或每个输入都会放大；本文只把该式作为充分上界使用。π定常时退回MATH114非扩张，常量模式排除全空间严格收缩。没有详细平衡、自伴或混合结论。

均值变化为 πᵀBf−πᵀf=rᵀf，并有

|rᵀf|≤(Σ_j r_j²/π_j)^(1/2)||f||π。

若每个j有真实上界r_j≤ηπ_j（η≥0），则ρ≤1+η。如果只有||r||∞≤δ，则ρ≤1+δ/π_min，π_min=minπ_j；下限缺失时，小绝对偏差不是小相对偏差。这些δ/η必须约束真实B、π，不能用有限经验计数冒充证书。

## 可复核推导

对每行取u_j=√B_ij、v_j=√B_ij f_j；CS给(ΣB_ijf_j)²≤(ΣB_ij)(ΣB_ijf_j²)=ΣB_ijf_j²。乘π_i求和得Σ_j(Σ_iπ_iB_ij)f_j²=Σq_jf_j²；再用q_j≤ρπ_j。ρ≥1来自π加权平均Σπ_j(q_j/π_j)=1；所有比值≤1且平均1强制各比值1。均值界是向量r_j/√π_j与√π_jf_j的CS。全过程有限实数精确代数，未调用谱定理。

## 四个公开问题与解析检查

全部用于开发，未见测试0；没有运行数值程序/Lean或模型拒用实验。

1. **双向交换槽位，选的权重并非真实平稳权重，还能保证能量下降吗？** B=[[0,1],[1,0]]，π=(2/3,1/3)，q=(1/3,2/3)，r=(-1/3,1/3)，ρ=2。f=e1→e0的平方范数1/3→2/3，恰好达到比值2，说明该上界在某些矩阵可取等号。原先正权重不能替代定常前提。
2. **更新后的权重几乎没变，是不是所有槽位都安全？** 令0<δ<1、0<ε<1，B=[[1−δ,δ],[0,1]]、π=(1−ε,ε)。r=(-δ(1−ε),δ(1−ε))，总变差||r||1/2=δ(1−ε)；ρ=1+δ(1−ε)/ε。但f=e1时平方范数比为1+δ²(1−ε)/ε。取δ=1/100、ε=1/1000000，总变差999999/100000000，平方范数比1009999/10000=100.9999，而ρ=10000.99。绝对误差小仍能放大，且界明显非紧。更强的族ε=δ³、δ→0给总变差→0而实际比值1+(1−δ³)/δ→∞。这是解析族，不是浮点扫描或对任意近似π的必要判据。
3. **封闭的两个等体积槽位只互换浓度，权重完全守恒是否意味着会均匀？** 取交换B、π=(1/2,1/2)。r=0、ρ=1，f=e0在e0/e1间周期振荡，范数不变，浓度和乘共同体积的总质量不变。映射保留离散交换与浓度单位，但不能当连续导热实验或从非扩张推混合。n=1也只有恒等非扩张，无全空间严格衰减。
4. **每行列和都为一且权重完全定常，是否可无视负系数？** B=[[2,−1],[−1,2]]、π半半，q=π会给形式ρ=1，但f=(1,−1)→3f，平方范数1→9。B≥0失败，平方根CS步骤非法，必须拒用本条。零π同样使除法/正定范数不成立。
