# 本轮研究取舍

延续 `../memory-storage-20261015/research.md` 的12篇方法/实验阅读矩阵，不能称为本轮新精读12篇。既有 LongMemEval/MemGPT 分层检索、依赖完整性与成本口径用于审查，不据此虚构质量提升。

本轮检索截至2026-10-19，筛选近期 Memory/Agent 研究；直接阅读 [AgentIR v1](https://arxiv.org/html/2605.25092v1) §3–5.1、§6，查阅§5.3/5.5及端到端耗时相关段落。不是全文/附录完整精读。方法提供条件化检索与省工思路，但本库拒绝直接迁移时间偏置裁剪或学习路由：它们不保证现有返回结果完全相同。其cascade部分延迟是分阶段数字推算，不能当墙钟实测；GPU排名一致性与完全逐位相同也不能混用。

本轮只采用“先判断后续工作能否影响输出”的工程原则：依赖数量已超过硬预算时，不装配必定丢弃的payload。它不是新检索算法、论文复刻或近似召回。CPU基准仍用完整context调用；加载+检索+装配另计，真实LLM任务质量/成本未知。

未采用 SIMD/GPU、新索引服务或新缓存：当前代码与115条语料不支持从外部大规模结果推出收益。profile只用于诊断；对照不使用profile时间。
