## 对象、假设与准确结论

同一概率空间，离散可数步骤t≥1，过滤族F_t包含该时刻全部实际可用历史。A_t∈{0,1}表示是否执行第t项检查，b_t∈[0,1]是分配给它的风险额度，二者均F_(t−1)可测；B_t∈F_t是所选择检查的真实失败事件。固定δ∈[0,1]。必须证明在整个允许过程上几乎处处

A_t P(B_t|F_(t−1)) ≤ A_t b_t，且 Σ_(t≥1) A_t b_t ≤ δ。

则P(存在t:A_t=1且B_t发生)≤δ。不要求各步独立，不保证没有失败，也不保证过程终止。δ=0时活动步骤失败概率为0；δ=1界可能无信息。b_t=0需要真实零条件风险，不能由小样本零失败推断。预算可以不用完，不能事后退款来撤销已发生事件的消费。

一般证明（本项目展开）：对任意N，逐点1_{∪_(t≤N){A_t=1}∩B_t}≤Σ_(t≤N)A_t1_{B_t}。条件期望和可测性给E[A_t1_{B_t}]=E[A_t P(B_t|F_(t−1))]≤E[A_tb_t]。求和≤δ；令N↑∞，事件连续性得可数步骤结论。相同证明也给EΣA_t1_{B_t}≤δ（非负项单调收敛），但本文不推导失败后的其他损失或系统安全结论。

若τ是相对于F_t的停止时刻，A_t=1_{τ≥t}是F_(t−1)可测，因此可用同一预算；它不允许看完本步结果再决定是否把这次失败算作检查。策略/模型由过去决定是可预测的，但可预测性本身不创造条件风险证书；每个历史下的真实选择仍需上述界。固定测试的边际界不能代替条件界。

经典出处：Stark, Berkeley SticiGui, Probability: Axioms and Fundaments，Bounds on Probabilities 段，网页未标稳定版次，2026-10-13读取可数联合界。条件化/活动步骤扩展为上述自推导，不归给作者。前置条件期望/塔式法则由已读math.betting-test-martingale@1正文重述。相关math.alpha-spending-stopping@1及其Hoeffding强依赖是固定对象、独立共同均值和确定范围的均值区间特例；不能将本文的条件事件预算解释成取消那张卡的iid/固定对象前提。

## 四个公开解析问题、反例与路由

全部是公开开发/审阅问题，未见测试0；没有模型自动识别/拒用实测。

1. 两阶段传感器检查，已认证在执行历史条件下第一步失效≤.02，第二步失效≤.03，整体至少一次失效最多多少？若步骤实际执行且条件证书成立，A1=A2=1，b1=.02/b2=.03给≤.05；不要求独立。具体U1/U2为相互独立且独立于检查前信息的均匀[0,1]变量，B1={U1≤.02}/B2={U2≤.03}给1−(.98)(.97)=.0494。这是解析严格概率映射，未测真实传感器。若仅两个固定边际事件各≤.02/.03，普通联合界仍给.05；自适应选出的第二事件必须另外认证。
2. 一百次检查，每次误报1%，整个过程也是1%吗？不保证。独立伯努利例为1−(99/100)^100>1/100（甚至前两次已有199/10000>.01），而所有B_t相同事件时整个概率仍.01。因此不能宣称依赖一定膨胀，或不假设独立就乘补概率；100次各.01的求和预算为1，不能声称总预算.01。预先改为每次≤.01/100才由联合界给总≤.01。
3. 已看到报告K，K均匀于{1,...,100}，每项固定测试j的失败事件B_j={K=j}，边际失败率均.01。按报告选j=K后风险是否仍.01？实际所选事件B_K=Ω，失败率1。K属于选择前F0，策略可预测，但P(B_K|F0)=1而非.01，故条件前提失败；按历史选择并非自动合法。整个固定族的联合界给≤100×.01=1，与反例一致。
4. 检查数量由历史决定且无预定上限，怎样保持总预算δ？可以预先设b_t=δ/[t(t+1)]，A_t由过去决定且每步具有真实条件证书，则ΣA_tb_t≤Σb_t=δ（有限和δ[1−1/(N+1)]）。任意这种停止的至少一次失败≤δ，不保证检查结束。这里“每步具有证书”是明确假设，不是用这一公式把任意评测改成有效检查；旧alpha-spending均值区间的固定过程前提仍须另核对。

## 迁移、限制与验证路径

Agent按历史决定是否发起校验→A_t；每次校验的具体失败→B_t；包含缓存、已看到答案、策略选择和训练更新的真实历史→F_(t−1)；风险额度→b_t。只有实际条件风险证书与不透支规则成立才是严格映射。任务“错误概率”“置信分”“总预算”字面相似但没有真实概率空间/证书时只是探索候选。风险无量纲，预算控制至少一次失败，不控制每个输入、失败严重度、token成本或延迟。

固定对象边际区间、有限菜单同时事件、序贯鞅和本应用的条件事件组合是不同接口。有限菜单可通过整个固定族同时覆盖处理选择，但不能只数幸存测试。后验概率、模型自报置信度、样本失败比例、总体MSE上界都不是自动的P(B_t|Fprev)证书。校准证书自身有失败概率时需要传播其额外预算和正确条件事件，不能忽略；本文未提供学习型校准器。

可证伪预测：case3选中失败率1；case1独立例至少一次失效.0494；case2边际.01不自动给过程.01。最小真实迁移先固定检查行为/历史信息/失败定义，验证每个允许历史的条件证书及路径预算，再在同模型/工具权限/预算保留任务上对照。本轮无实际消费者证书，故不改路由、早停或生产风险宣称。
