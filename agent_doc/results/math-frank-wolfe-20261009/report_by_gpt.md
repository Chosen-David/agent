# 固定凸输出的轻量迭代求解与停止证书_by_gpt

对应 MATH-54。本轮新增可按需检索的 `math.frank-wolfe-output-solver@1`，补上从“知道最优误差存在”到“逐步产生合法权重、认证距最优还有多远”的数学方法。没有生产、模型或GPU收益证据，未修改SGLang。

## 能解决什么

给定固定选中原value集合和已知dense teacher输出z，求非负、总和为1的权重，使输出接近z。每步取最大残差内积的原value，向它移动；线搜索只需计算一个标量并截到[0,1]。可行更新始终保持归一化。

令f=半平方输出误差、h=f−最优f，D是凸包直径。完整oracle计算gap g，满足h≤g。固定步长2/(t+2)和精确线搜索都满足h_t≤2D²/(t+2)，t≥1；线搜索单调，但固定步长并不单调。证明、单位、误差因子及精确条件在知识条目中；数值样例不是一般证明。

停止判据g≤ε界定“平方误差比本子集最优最多多2ε”，不是绝对误差必然小，也不证明末步gap自动按1/t下降。部分候选max可能误报g=0；只有认证oracle缺口η，才可用g_hat+η认证。

## Indexer与跨域迁移

这是一项离线诊断：比较原softmax子集权重与允许重赋权后的误差，区分子集几何不足和权重未调好。需固定query、原values及目标；若权重不能改变，只把求解器当诊断基准。每步穷举oracle约O(np)，显式全权重更新O(n)，dense目标获取也有成本；不将投影-free等同于线上提速。

配方/传感器均值拟合同样保留非负单位质量约束，可严格映射。负权回归、未知或变化目标、修改values、跨query共享以及非线性e2e不在保证内。新增方法没有改生产注意力行为。

## 实际验收

- 10个公开案例，其中8个合法凸包、空集/负权两项拒用；两种policy各12步，共192次Fraction精确更新。独立解析最优值、simplex、oracle ties、递推和gap核查通过。
- 保留固定步长首步上升：v=(0,3)，z=5/6，f由25/72升至169/72；线搜索一步达到目标。
- 保留假停止：v=(0,2,4)，z=4，y=2，只看0和2得到gap0，完整gap4，实际距最优h=2。部分max不能作全域停止证据。
- 无定理名称的三条结构问题含配方跨域及误用，文件与SQLite共6/6命中。只报告结构检索；未做模型推理、拒用或未见验收。
- 53项知识定向回归、镜像check、独立安全重跑通过。另一个真实上下文复算192次更新并核对488份绑定（含协议），状态usable-with-scope。相关代码/原始数据/协议/回执保留在本目录。

检索context加载新条目与两条强前置，共11,417序列化字符；预算为3项/16,000字符。context=partial仅省略可选关联条目，强前置完整；这不是全相关知识已读。实际token未测，字符数不当token或节省比例。时间保留在raw/retrieval记录中，仅为本机诊断，不是性能比较。

## 失败、限制与下一步

计划审查首先纠正了“固定schedule也单调”的错误验收，cycle1反馈和修订绑定保留。第一次检索脚本误要求context=ready，拒绝了实际完整强前置/可选关联被预算省略的partial包；原脚本/数据保留在failed_attempt1。第二次只修复状态断言，未改查询、语料或预算；独立复核了修复差异。

一般数学证明为非形式化审查，没有Lean、浮点外包或大规模优化器认证。没有实际模型/GPU/线上延迟、精度、token或e2e收益。公开测试已用于开发，不再算未见；既有留出题仅校验元数据文件摘要，未读取题内容。已有结果搜索保留partial和取舍，旧数值不复用。
