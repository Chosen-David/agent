这里的 **attention mass 是候选位置在目标层完整注意力分布中占据的权重总和**，所以答案是 **0.65，也就是 65%**。不是把候选层的分数和除以目标层 top-k 的分数和。

固定题目给定的同一目标层、query 和 head，令 \(a_i\) 为 token \(i\) 的完整注意力权重，候选集合为 \(S\)，则

\[
M(S)=\sum_{i\in S}a_i=a_0+a_2=0.50+0.15=0.65.
\]

先看 **P1**：横轴是 token 索引，纵轴是目标层注意力权重；蓝色斜线柱对应集合 \(S=\{0,2\}\)，分别拿到 0.50 和 0.15。再看 **P2**：把这两份相加，它们覆盖了整份注意力的 65%，剩下 35% 在 token 1 和 3 上。图中数值是题目提供的教学数据。

如果你更习惯“占比”的写法，也可以写成

\[
\frac{\sum_{i\in S}a_i}{\sum_{j=0}^{3}a_j}
=\frac{0.65}{1}=0.65.
\]

这里的分母是**完整分布的总和 1**。候选位置即使由另一层筛选，计算这个 mass 时也只是借用它给出的索引集合，再回到目标层取这些位置的权重；不能混入另一层的分数，也不能把 softmax 前的 logits 当作这里的权重。

如果另外定义“相对目标层 top-2 的覆盖率”，目标层 top-2 是 \(\{0,1\}\)，其权重和为 \(0.75\)，于是得到 \(0.65/0.75\approx86.7\%\)。这是另一个归一化指标；其分子仍然取目标层在候选位置上的权重。

在这里的定义下，\(M(\varnothing)=0\)，选全体 token 则 \(M=1\)。所以你可以把本题读成：“这两个候选位置，保留了目标层这一个 query/head 的 65% 注意力权重。”
