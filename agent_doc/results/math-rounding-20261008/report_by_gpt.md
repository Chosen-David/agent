# 浮点点积外包与严格安全筛除_by_gpt

本轮增加 `math.floating-dot-enclosure@1`：在明确算术前提下，给存储的有限 binary64 向量的精确实数点积构造逐运算外包；将坐标粗筛的遗漏项误差纳入区间，以严格上界小于第 k 大下界作为可安全删除条件。它补齐实数筛除推导到浮点验证之间的一部分缺口。

## 数学与迁移

逐个乘积用相邻浮点数向外扩展，区间加法对两个端点向外扩展，乘法检查四角。正确舍入、渐进下溢、有限端点成立时，单步包含及归纳给出包含精确存储值点积的区间。gamma 的相对误差模型另有正常算术条件，不能覆盖任意下溢；最终结果仅扩展一 ULP 不能弥补抵消时已丢失的小项。

坐标子集 S、遗漏子集 H 对应实际粗筛；遗漏绝对误差用 max_H|q| 乘 sum_H|k| 的外包控制。若 U_i<tau（第 k 大下界），可删除；相等必须保留。完整精确分数重排恢复该数学目标的 Top-k。候选可能保留全部，没有加速保证。任意学习投影、原始量化输入、理想 RoPE 与真实 GPU kernel 的输出均不是这个精确目标，须独立误差证书；条件未知则保留或回退。未修改 SGLang 或生产行为。

跨领域检查为电导与电压的线性组合：S×V=A，确切电流 3/8 A 被外包。此为合成检查，不是实测传感器误差认证。

## 实际验证与成本

公开开发数据：103组精确有理数点积外包、64个乘法角点、24组坐标粗筛，以及9个拒用/回退案例。抵消、次正规、溢出、ties、FTZ、量化原始值未知均有明确边界。自然语言证明审核与有限样例不能冒充 Lean 形式化证明或平台证书。

独立上下文复核执行1,244个检查及7个额外拒用条件，包含800组额外随机抵消/次正规/符号案例，重建原始数据和检索；详见 independent_report.md。所有披露案例均成为回归。保留既有未开发测试元数据；另一个未来测试规格仅记录位置/摘要，未执行，不能报告未见测试通过。

三个无定理名称查询在文件和 SQLite 后端共6次均命中正确 ID。按需只加载一张卡，6808字符，预算12000字符；字符不等于模型token，本轮未测token或模型检索/拒用质量。

相关回归52项通过；全量851项通过（8跳过）；reader检查3项通过；插件同步检查通过。首轮状态文件改动后未同步插件副本导致失败，已保留原始失败证据并重新同步后通过。检索脚本首次误把 API ready 状态写成 complete，失败原稿和日志保留，修正为实际接口后通过。

CPU执行时间为诊断记录，原始数据约0.019秒，独立检查约0.24秒；详细时间在 raw.json、execution_v2.json、retrieval.json。没有同模型同预算 A/B，没有GPU或e2e精度/速度实验，不能称性能提升。来源、代码、协议与原始数据将以 manifest 哈希冻结，经独立接收回执和宿主门禁后发布；发布提交状态另见 publication_receipt.json。
