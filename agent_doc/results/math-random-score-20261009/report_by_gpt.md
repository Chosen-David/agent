本轮补齐 `math.gaussian-projection-score@1`。已有按需加载入口 `model-with-knowledge` 可检索它及排名间隔前置知识；未新增 Skill 或改生产行为。新增的是核验后的知识与结构检索支持，没有模型实测，不能报告 Agent 整体能力或性能提升。

## 数学结果与迁移

对独立于投影的有限 Q 个 query、N 个 key，A 条目 iid N(0,1/m)，通过 chi-square MGF、Chernoff、有限事件 union bound 与归一化极化，推得同时内积误差 `epsilon ||q||||k||`，充分维度 `ceil(log(4QN/delta)/(epsilon²/4−epsilon³/6))`。排名另需严格分界 gap；样本误差、平均误差都不能替代完整前提。

迁移对应冻结的 NoPE query/key，或先完成 RoPE 的固定向量，再投影。先投影再采用代表频率旋转不由此保证；混合结构需保留实际 scale。传感器模板打分可采用同一数学映射。未证明真实在线轨迹独立于 sketch，未测试 GPU/量化/缓存成本，也未证明 attention output/e2e 收益。

两条明确负结果：事后选择 ker(A) 输入破坏独立条件；P=[1,1] 对 g=e1 精确保留内积，但 F=diag(1,99) 的逆目标从1变1/100。保几何不自动保求逆。Q=1,N=1024,epsilon=.2,delta=.05 的保守充分维度为1306，超过d=128；它不是可用的最佳压缩维度求解器，不证明低维经验方法全部失败。
