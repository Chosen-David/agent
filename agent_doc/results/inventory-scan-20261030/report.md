# Inventory scan errors: refuse unknown subtrees

`build_artifact_index` and `snapshot_project_docs` previously used `os.walk` without an error callback. A root or nested `scandir` failure could return a successful empty/partial inventory, concealing a required artifact or advice file. Both walks now reuse one existing-module callback that raises `DocumentError` with the original `OSError` as its cause. Readable paths, hashes, required matching and absent optional document behavior remain unchanged. The bundled Skill already links to the same source; its symlink is preserved, with no second implementation.
