## Mathematical assessment before any producer run

T6: row(F)=(1/2,1/4), col(F)=(1/4,1/2). Neither clipping step changes F. Thus r=(0,1/4), s=(1/4,0), tau=1/4, and completion adds 1/4 only at (2,1). Every G entry is 1/4. With v=(0,2), both off-diagonal costs are 2: U=2(1/4+1/4)=1. The old 1/2 counted only the added off-diagonal contribution and omitted the original one. Corrected frozen expected_U=1 is necessary and correct.

For arbitrary stated full-support finite inputs, 0<=Y<=X<=F. Row clipping gives row(X)<=a; column clipping gives col(Y)<=b without increasing row sums. Therefore nonnegative deficits have equal total tau=1-sum(Y). If tau=0 all deficits vanish; if positive, rs^T/tau has row/column deficits exactly. G is feasible. With delta=sum(F)-sum(Y), triangle inequality gives ||G-F||1<=delta+tau. Nonnegative bounded costs give <Y,C><=<F,C> and completion cost <=D*tau. For sum(F)=1, delta=tau; clipping removal <=half of each original marginal L1 residual, yielding the stated residual-sum bound. This is correctly distinguished from the cited paper's stated constant.
