# 固定输出的凸支持约简：验证与迁移边界

本轮新增 `math.convex-support-reduction@1`：把仿射秩、核内消元和非负单位质量约束接入已有知识检索入口，不新增Skill或生产runtime行为。经典来源为Paquette讲义§1 Theorem1；仿射维数r+1精化及Indexer映射明确为项目推导。

## 数学与具体迁移

增广列(v_i,1)的rank=r+1。正支持大于此数时，在核中选a，Σa=0，按最小正比值消元一项，保留质量、非负和固定输出；有限步约简。r维simplex内部点需要r+1项，最坏界紧。

Indexer固定query输出可有少量value的重新赋权表示，但原softmax子集通常不等价。v=(0,1,3)，α=(1/2,1/3,1/6)时z=5/6；极端点新权重(13/18,5/18)保真，同子集原权重归一化得到3/4，误差1/12。固定W降维只能保真Wz，不能保真raw z。传感器均值是成立的跨域映射，协方差/未来query不是自动保留的关系。

可证伪候选：在离线dense teacher已知的校准输出上，比较相同支持预算的原权重子集与允许重新赋权的输出误差，估计value冗余能否解释低overlap仍低输出误差。当前只验证数学可能性，尚无真实trace或模型e2e实验。不得据此修改生产注意力或声称加速。
