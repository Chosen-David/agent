## 数学结论与边界

设 A 可逆，B=A+UVᵀ，S=I+VᵀA⁻¹U。B 可逆当且仅当 S 可逆，且 B⁻¹=A⁻¹−A⁻¹US⁻¹VᵀA⁻¹；U、V 不要求列满秩。条目给出块消元证明和乘法核验，并区分公式与推荐实现：复用线性求解，不以显式求逆作为默认实现。

若 A 正定，A+uuᵀ 正定；A−uuᵀ 正定当且仅当 uᵀA⁻¹u<1。等于1时奇异，大于1时仍可能可逆但不再正定（维数1时为负定）。这能防止把“可逆”误当作合法协方差。

公式在实数中正确不保证浮点算法稳定。实际 Python binary64 测试取 A=b=v=1、u=2^54，按标准 Sherman–Morrison 运算顺序返回0，而精确解为1/(1+2^54)。真实归一化残差和相对前向误差均为1，两个标量系统的条件数均为1，分母也不接近0。该反例针对所记录运算顺序，不是所有实现的失败证明。

## 具体迁移

在线 ridge 回归使用未归一化 C=λI+Σxᵢxᵢᵀ 和 h=Σxᵢyᵢ。新增观测时必须同时更新 C 和 h。固定案例 C=diag(2,3)、h=(1,1)、x=(1,2)、y=2 得到新解(11/17,9/17)，精确有理数验证通过。

这可用于 indexer 离线校准或传感器回归的重复求解。矩阵、观测和右端项的对应关系是精确的；与注意力质量的联系仍是候选。中心化/归一化协方差不能直接照搬此更新。下一步应在固定数据与预算下比较直接分解、因子更新和候选修正算法的残差、累计误差及总开销；不得仅据复杂度宣称加速。
