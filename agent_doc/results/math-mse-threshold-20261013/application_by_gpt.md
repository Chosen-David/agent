## 数学对象、假设与准确结论

固定真实总体概率律、固定预测器 f，真实数值目标Y，允许依赖观测Z，误差 R=Y−f(Z)∈R；可包含偏差与依赖。假设真实 E[R²]≤V<∞，V≥0为已证明的确定上界，阈值τ>0预先给定。无需 R 均值零、正态或样本独立。事件定义为幅度至少τ（含等号）。则

P(|R|≥τ)≤min(1,V/τ²)。

证明：逐点 R²≥τ² 1_{|R|≥τ}，期望给 E[R²]≥τ²P(|R|≥τ)，再用真实V上界。一般结论依赖这个逐点证明，不由四个例子代替。若 R 有有限二阶矩，E[R²]=Var(R)+(ER)²；仅 Var(R)≤V 能控制围绕真实均值的偏离，不是围绕预测正确值0的总误差。真实均值0已证明时才可将真实方差界当MSE界。

固定同单位向量误差e、固定Euclidean范数也有 P(||e||≥τ)≤E||e||²/τ²，由同一非负证明。已知真实误差均值b和CovΣ时 E||e||²=trΣ+||b||²。异量纲坐标要先定义合理固定度量，不能直接把不同单位平方相加。本文没有验证向量数值实现或实际多输出模型。

V=0推出R=0 a.s.；不推出所有支持外输入无误差。τ≤0拒绝该接口；负V非法，∞上界无有限证书。界截断到1而非宣称概率超过100%。对0<δ<1，选择τ≥√(V/δ)是总体尾概率≤δ的充分条件，通常保守，不是精确分位数或Gaussian区间。

## 总体、样本、代理与条件的边界

样本MSE、训练损失、模型报告的方差Q，都不自动是总体E[R²]的上界。MATH101已说明合法代理协方差不等于真实条件误差，旧文档引用只用于条件检查，不更新其验收。没有覆盖概率/总体矩证书时拒绝代入；学习得到随机V另需其证书及失败概率传播，本记录不提供通用校准器。

若要按每次观测Z=z报告失败概率，需要真实 E[R²|Z]≤V(Z) a.s.，而非仅总体E[R²]≤V。用条件期望对同一逐点不等式得到 P(|R|≥τ|Z)≤min(1,V(Z)/τ²) a.s.。只知总体V时仅有总体尾界，不能把V搬到每个观测条件上。f固定但依赖Z是允许的；阈值/度量/模型根据数据自适应改变时需明确新的事件与条件证书，固定条目不会自动认证停止/筛选策略。

## 四个公开解析问题和前提路由

全部已用于开发与普通文档审阅，未见测试0；没有模型检索、拒用或推导A/B实测。

1. 一个传感器估计的真实均方误差已被证明不超过4 mV²。误差至少10 mV的概率最多多少？R为同工况总体误差、V=4、τ=10，界为4/100=0.04；非零偏差已包括在MSE中。只是假定有真实证书的解析成立例，无传感器测量或物理建模实测。
2. 零均值误差取−10和10各概率1/200，其余取0。能由MSE=1断言10倍尺度误差几乎不发生或给Gaussian尾吗？E[R²]=100/100=1；P(|R|≥10)=1/100，恰达到V/τ²。另一个误差始终±1（各1/2）也有MSE1，在τ10尾概率为0。相同MSE不决定精确尾概率；除给出的真实分布外，不添加正态尾假设。
3. 预测误差总是5，误差方差为0。用方差0能证明幅度至少1的失败概率为0吗？不能：VarR=0但ER=5、MSE25，实际失败概率1；正确MSE界min(1,25)=1。中心化方差界控制的是R−ER而非R。
4. Y取−1,0,1，概率1/4,1/2,1/4，观测Z=Y²，固定预测f=0。总体MSE1/2能否对每个Z都报幅度至少1的失败概率≤1/2？总体事件概率1/2，界成立且紧；Z=1时实际条件概率1，Z=0时0。真实条件MSE为Z，条件界分别1、0。复用MATH100案例的总体/条件分离，拒绝把平均界当逐工况界。

附样本误用边界：案例2同分布独立抽n个校准误差，全部0的概率(0.99)^n>0，观测样本MSE0仍可能对应真实MSE1。这里独立仅用于计算这次“漏掉稀有值”的事件概率，不是Markov一般结论的前提。样本全0不能独自提供确定总体上界0。
