## Object and benchmark

Each supplied memory block contains atomic propositions with target response influence Ignore/Bound/Control: no answer-specific footprint, bounded local support, or a material conclusion/constraint. These are normative task annotations, not permission, source truth or proof that a provider received complete context. Observable use includes rejecting/correcting/warning about an atom; acceptance of its content is not necessary for use. The judge sees atom text, target and rubric, although instructed to classify actual footprint before comparing with the target. This is rubric-guided evaluation, not an independent truth oracle.

The construction pipeline uses eight public QA sources: MedDialog and ChatDoctor–HealthCareMagic; UltraChat200K and OASST1/2; StackExchangePreferences, APPS and MagicoderOSS-Instruct. Qwen3.7-Max performs source screening, extraction/query rewriting, atomic target annotation, distractor/rubric generation and paragraph naturalization. ## Metrics and judge limits

Map target/actual influence to ranks0/1/2. Per response O=sum max(actual-target,0), U=sum max(target-actual,0). With rho=.5, sMOS=mean(1-rho^O), sMUS=mean(1-rho^U), SCS=mean rho^(O+U), Exact=fraction[O+U=0]. AOR/AUR are fractions of responses with any error in the respective direction. All are scaled0–100 for tables. These are response-level rather than atom-micro averages and depend on atom composition/count. They are not probabilities of scientific validity or final task success.

DeepSeek-V4-Pro judges actual use. Evaluation is non-thinking, temperature1/top-p1 with mean±SD over three seeds; this is not established as three independently retrained checkpoints. AppendixC human review uses300response-atom pairs:150natural random plus150stratified over nine ideal/judged-actual combinations. ## Training method

Nine ideal–actual channels reward matching influence+1, mismatch minus ordinal distance, normalized by the number of atoms with that ideal level(max1). All atom members of a nonempty response-channel are ablated together, preserving other atoms/order; this is not one independent ablation per atom. Teacher-forcing the SAME generated response with the SAME rollout policy gives d_t=logp_full-logp_ablated. Positive d supports generated tokens; negative d indicates memory-suppressed but still generated content. Realized/excess use targets positive d; under-use targets negative d to avoid penalizing already correct memory influence. Correct Ignore/Ignore keeps sequence reward but has no localization. This fixed-response likelihood proxy is neither regenerated-answer intervention nor guaranteed causal token attribution.

Direction-aligned d is clipped; an absolute signal gate plus channel EMA threshold/ReLU gives q. Thresholds start.02, candidate max(.02,75thpercentile), updated.9old+.1candidate after a batch only with>=256 pooled token scores from successfully scored counterfactuals, not256 ablation runs. Token weights q/sumq become T*q/sumq. Implementation projects multipliers into[0,4] with a shared bisection offset maintaining mean1, then blends uniform/local credit with eta=.75. Redistribution requires R*A>0 and nonzero signal; failures/unavailable counterfactuals revert to sequence credit. Channel advantages are group-normalized, summed per token and RMS-normalized using ORIGINAL sequence channel sums; epsilon1e-6. Mean response advantage matches GDPO, but gradients and update trajectories can differ.

D4 authors report max numerical mean errors7.15e-7/channel and1.43e-6afteraggregate;99.84%localized instances hit multiplier cap. Eta.75 gives effective maximum3.25, not4. These are author numerical diagnostics, not our tests or a compute-saving result. The clipped objective is response-token-weighted across the batch and includes reference-KL notation. Exact unspecified hyperparameters, hardware, total counterfactual/judge calls and retry cost must not be filled in from assumptions.
