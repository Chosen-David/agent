Its minimum uses E lower/C upper endpoints, maximum uses E upper/C lower endpoints. Endpoint vectors belong to the Cartesian box, so these bounds are attained. Empty/full events give 0/1 without evaluating invalid empty logarithms or dividing rounded zero sums. Finite logits on nonempty J imply a positive exact denominator. Distinguish this sharp Cartesian-box result from a potentially conservative bound on correlated realizable logits.

Numerical realization needs separate certified A/B intervals for the extrema: m >= A_lower/(A_lower+B_upper), m <= A_upper/(A_upper+B_lower), with outward basic operations and strictly valid denominator handling.
