# 视频讲解验收 v1

用户要求：在现有知识讲解 Skill 中接入视频，参考3Blue1Brown的视觉推理方法。

- 安装包能发现按需视频工作流与独立可运行检查脚本；不改变简单问答或网页默认行为。
- 分镜必须有贯穿例子、每场读图问题、旁白、可见操作及有序时间边界；字幕不能越场或重叠。
- 真实 ffprobe 检查实际输出的视频、音轨、尺寸与时长；无声片、时间轴不匹配应明确拒绝，缺后端不算通过。
- 至少用真实 FFmpeg 夹具执行合法片和无音轨负控；修改素材字段/时间边界的负控应因相应诊断拒绝。
- 机器技术检查通过仍保留教学/听感人工自检未决；不声称学习质量、中文TTS或Manim/Remotion已安装。

- HTML按需引用同一教学/视频规范，覆盖真实数值互动、reset、离线媒体、字幕/文字回退和浏览器实际播放；静态路由检查不冒浏览器或教学效果验收。
