# 近似因子怎样提供原系统证书

稳定ID：candidate.singular-boundary-condensation@3；2026-10-10。这是既有@1/@2的不可覆盖补充，仅处理可逆实对称子范围；按需先读@1的对象/分区与@2的原系统残差。状态：项目自推的经典结论组合、普通文档审核候选；不增加canonical条目或Skill，不改求解器。

## 对象、前提与准确结论

给定原系统Hu=h，H实对称；此处不预先假定H正定。L为已确认可逆的实方阵（实际通常三角，必须核验全部非零pivot），P=LL^T。上标-T表示逆转置。定义精确白化缺陷

F=I-L^-1 H L^-T。

需要真正认证的q>=||F||inf，且0<=q<1。普通浮点算出的残差或条件数估计不是认证。F对称，因此每个特征值绝对值<=||F||inf<=q：取特征向量最大绝对值分量，用对应行绝对和即可证明。

H=L(I-F)L^T，故(1-q)P <= H <= (1+q)P（Loewner序），特别地H正定。由Neumann级数||(I-F)^-1||inf<=1/(1-q)。若U_L>=||L^-1||inf和U_LT>=||L^-T||inf都已认证，则

||H^-1||inf <= U_H := U_LT U_L/(1-q)。

这里两个因子不能随意合成U_L平方；转置会把行和变为列和。2范数版本可以使用||L^-1||2平方/(1-q)，但须各自认证，不能混合范数。

这些是有限维精确代数和已有Neumann/对称谱事实的项目推导，不是新定理。q>=1只代表充分条件失效，不证明H不定/奇异。H非对称时上述正定合同证明不适用，不能静默对称化。

## 从近似三角求解到误差

任意近似解u_hat，令s=h-Pu_hat为代理系统残差；z_hat=L^T u_hat，t=L^-1 s，u_star=H^-1h。精确恒等式

(I-F)L^T(u_star-u_hat)=t+F z_hat。

由于||F||2<=q、||(I-F)^-1||2<=1/(1-q)，若T>=||t||2认证，则

||u_star-u_hat||P := ||L^T(u_star-u_hat)||2
<= (T+q||z_hat||2)/(1-q)。

浮点计算z_hat也需误差包络。s=0时得到q/(1-q)乘近似解P范数的绝对界；零解不做相对除法。原系统残差仍是

r=h-Hu_hat=s+L F L^T u_hat。

用@2误差公式时必须提供原系统r的认证包络；不能把s替换为r。已认证||r||inf<=R时，||u_star-u_hat||inf<=U_H R。给A与Schur矩阵S分别认证可为@2供应H_A/H_S，但局部证书不自动认证整个原系统，也不证明跨机任务独立。

## 公开解析验收与误用反例

以下题目没有要求调用某定理名。它们已用于开发及审核，不能再算未见测试；没有模型自动检索/拒用实测。

1. “H=diag(0.9,1.1)，用L=I求h=(0.9,1.1)，能给多大误差界？”F=diag(0.1,-0.1)，q=0.1，U_H=10/9。P精确解u_hat=h，真解(1,1)；P误差sqrt(0.02)，证书为||h||2/9，确实覆盖。原残差(0.09,-0.11)，inf解界11/90覆盖实际0.1。
2. “因子相对残差趋零是否证明解准确？”H=diag(epsilon,1)，0<epsilon<1；L=diag(sqrt(epsilon/2),1)。||H-P||inf/||H||inf=epsilon/2趋零，但F=diag(-1,0)，q=1不能认证。h=(epsilon,0)，代理解(2,0)，真解(1,0)，误差1不随epsilon缩小。小因子误差不能替代白化证书。
3. “两次逆三角范数都取同一个行和行不行？”令L^-1=[[1,0],[1,1]]，则||L^-1||inf=2而||L^-T||inf=2，本例相等并不能证明通则。改成L^-1=[[1,0,0],[1,1,0],[1,0,1]]，行和最大2、列和最大3；U_L平方4不能代替所需产品6。更直接令L^-1=[[1,0,0],[1,delta,0],[1,0,delta]]，0<delta<1/2，且H=P（q=0），||H^-1||inf=3+2delta > (1+delta)^2；错误平方界实际失效，尽管L可逆。
4. “测出q=2是否证明原系统坏了？”H=3I,L=I得到F=-2I，q=2，而H仍SPD；结论只能是本证书不成立。另H=diag(-epsilon,1)，L=diag(sqrt(epsilon),1)给F=diag(2,0)，原始因子相对残差2epsilon虽小，原H却不定。仅由q失败不能分类这两个问题。
5. “移位后能成功分解，能否接受原方程？”H=diag(-1,1)，分解H+2I=diag(1,3)得到L=diag(1,sqrt3)。对原H的F=diag(2,2/3)，不满足q<1；对移位矩阵缺陷为0仅认证另一个系统。解、残差和物理对象必须用原H核验。
6. “接地电路近似回代还剩电流偏差怎么办？”H=2 siemens,L=sqrt2，q=0，h=2 ampere，u_hat=0.9 volt。s=0.2 ampere，T=0.2/sqrt2；P范数真实误差sqrt2*0.1，恰等证书。U_H=0.5 ohm，U_H R=0.1 volt也恰等。P范数平方单位是siemens*volt^2（watt），在电阻电路中是功率二次型，不称储能；L单位sqrt(siemens)，F无量纲。
7. “零pivot却原始因子误差小能否继续？”H=diag(epsilon,1)，L=diag(0,1)原始差epsilon小，但L不可逆，F未定义，必须拒用。孤立/浮动电路gauge属于@1奇异兼容性，不通过本补充处理。

## 输入和浮点边界

名义H与真实H_true=H+DeltaH不同，且DeltaH仍对称时，F_true=F-L^-1 DeltaH L^-T。必须将认证的||L^-1 DeltaH L^-T||inf上界加到q；总和<1才认证整个允许矩阵族。真实h=h_nom+Delta h时，R_true <= R_nom+||Delta h||inf+||DeltaH||inf ||u_hat||inf，各项也要认证。未知输入误差不能设零。

若算得F_hat，至少需要外包||F-F_hat||inf<=eta，并取q>=||F_hat||inf+eta。三角逆、缺陷构造、行和、输入缩放、FTZ/overflow和转置通信都须纳入外包与元数据。此轮未实现区间/有向舍入，因此只给可复核解析条件，不认证任何实际浮点矩阵。形成稠密白化缺陷及逆界可能比原求解更贵；安全因子也不代表有效预条件器或更快收敛。
