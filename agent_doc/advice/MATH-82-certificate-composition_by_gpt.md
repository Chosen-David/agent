# 风险上界证书的不确定性怎样计入任务风险

稳定ID：`candidate.calibration-certificate-composition@1`；2026-10-11，解析文档候选，不是canonical卡或生产策略。前置：有限条件概率、全概率、并集界。关系：MATH81先假定逐历史hazard证书真实；本条处理证书可能失效这一外层。`math.finite-menu-selection@1`给冻结菜单的同时均值控制；它不生成逐历史证书。本条不重复估计公式，不继承旧CPU实验。

## 对象、假设和精确结论

有限校准变量D按P_D分布。对每个正概率d，整个实际部署实验W有指定概率核P_d，允许策略/任务分布随D改变；无需D与W独立，但P_d必须是实际部署条件分布。E为W中定义明确的失败，R(d)=P_d(E)∈[0,1]。

G∈σ(D)为证书正确事件，P_D(G)≥1−δ，δ∈[0,1]。在每个good d上R(d)≤r，r∈[0,1]是确定数。G未必能被部署者识别，且不是看未来失败后挑出的成功子集。则联合校准/部署概率满足

\[
P(E)=E_D R(D)\le r+(1-r)\delta\le\min(1,r+\delta).
\]

这是外层校准置信与内层实际风险的组合；不是以1−δ概率每次行动必成功，也不保证当前这份D属于G。若good d上仅R(d)≤b(d)，b(d)∈[0,1]，则P(E)≤E[1_G b(D)]+P(G^c)。不能把只在G上成立的b任意替换为无条件均值或当作所有历史真实hazard。

**证明。** 逐d全概率，令q=P(G^c)≤δ：E R≤rP(G)+P(G^c)=r+(1−r)q≤r+(1−r)δ。更一般同样逐d求和给加权界。无需G和E独立；最坏bad d风险1，good d风险r，故常数界可达。r=1或δ=1平凡；δ=0回到r；r=0仍有δ；确定D时good/bad状态须单独满足，不能用重复随机校准的频率证明这份D绝对安全。

## 证书族、选择与任务链

对有限K个G_j∈σ(D)，各P(G_j^c)≤δ_j，G=∩G_j，则P(G^c)≤δ_*:=min(1,Σδ_j)，不要求证书独立。若每个good证书对候选风险R_j(D)有上界U_j(D)，则共同G上，对任何D可测选择J(D)，R_J(D)≤U_J(D)。要得到上述r界还须在共同G上U_J≤r，且选择无获证候选时采用的fallback也单独纳入风险；空可行集合不等于安全。不能沿用选中项自身δ_j而忽略搜索范围。

共同G可以覆盖多个步骤，不要把同一个全局证书的δ逐步重复相加；不同证书或没有共同事件时也不能只收一次。对每个good d，在冻结P_d内重新核对MATH81全历史hazard和预算，若推出任务链R(d)≤r，才把r放进本条。给定校准数据的总体风险上界，仍不是给定实际任务历史的条件风险上界。

有限校准时点的逐项保证同样需要共同事件；某个固定n的置信区间不自动允许不断查看数据直到通过。真正时间统一保证控制∀n的事件，可覆盖允许的选择时点，但其风险对象、数据/模型前提仍须检查。在线证书依赖部署未来时，不能直接把它当本条校准前G，也不能条件于“整条链没出问题”重新推hazard。

## 六个公开结构题与误用反例

1. 校准正确概率≥.9，在正确校准条件下整个部署失败率≤.02。问联合失败率：≤.02+.98×.1=.118，不能报告.02。让D以.1概率bad且bad失败恒1、good以.02失败，就达到.118。
2. 一份共同证书覆盖整条链，δ=.1；对每个good d，已另证全链风险≤.2。联合风险≤.28。不是每步都再次收费同一δ，也不能漏掉δ。共同证书范围若只涵盖一个动作则本例不适用。
3. D均匀于十个ID；十个候选j在D=j时风险1、否则0，均报U_j=0。每个G_j={D≠j}正确概率.9。允许J(D)=D，选中风险恒1；各自90%正确不提供选择后90%证书。共同G为空，Σδ_j=1给平凡界。这里选择可测、实际P_d可有限构造；不是声称部署者一定知道真实风险，而是反驳任意数据依赖选择的保证。
4. 即使D证书总正确，任务类型C为bad概率.01且仅bad失败，则总体风险.01、bad历史风险1。δ=0不能把总体风险升级逐历史hazard，更不能部署只选bad后沿用原风险。此为风险对象/分布失配，非外层δ算术问题。
5. 在十个预定查看时点，G_n^c={D=n}且D均匀于十ID，每个固定时点证书失效率.1；所有时点同时正确概率0。保证“每个n分别≥.9”不是“∀n≥.9”。自适应选择坏时点可使失效恒发生；固定n的结果不能冒充anytime。
6. 跨域：传感器批次的联合校准事件概率≥.95；每个good批次，在声明现场分布下下一次误报警率≤.04。联合误报警≤.04+.96×.05=.088。概率无量纲，校准批次和现场风险是两个不同随机层；读数单位/传感器漂移不自动被此界覆盖。未运行物理实验。
