# 分块消元：完整残差与消费者目标量的误差

稳定ID：`candidate.singular-boundary-condensation@2`。2026-10-10，AI作者，Task MATH-76。**不可覆盖的版本补充**：须与[MATH-75的@1](MATH-75-singular-condensation_by_gpt.md)共同读取；@1的奇异范围条件保留，本补充的逆范数证书仅覆盖下述可逆SPD子范围。仍是文档候选，不在canonical语料，不是新Skill或部署代码。

## 1. 触发结构、对象与条件

科研消费者要解固定实对称系统 `H u*=h`，其中

H=[[A,B],[Bᵀ,D]]≻0，u*=(x*,y*)，h=(f,g)。

A为m×m，B为m×n，D为n×n，m,n≥1；x内部变量、y保留边界，分区及原输入固定。SPD保证A与S=D−BᵀA⁻¹B都SPD。b=g−BᵀA⁻¹f。近似解û=(x̂,ŷ)可以来自任意算法。本条所有身份首先使用精确算术与精确原输入；“逆”是数学记号，实现应调用solve。

目标可以是全解或给定线性观测J(u)=cᵀu，c=(c_I,c_K)。范数证书用向量∞范数、诱导行和矩阵范数；线性观测配对用1范数。对象、单位和原坐标必须相容。未知精度、非线性消费者或浮动gauge不能默认为满足条件。

## 2. 两块完整残差与精确边界残差

定义原系统残差

r_I=f−A x̂−B ŷ， r_K=g−Bᵀx̂−D ŷ。

本项目自推代数身份（非新定理）：

t:=b−S ŷ = r_K−BᵀA⁻¹r_I。

证明：用A⁻¹r_I=A⁻¹f−x̂−A⁻¹B ŷ直接代入，x̂项抵消。只有r_I=0时，完整边界块残差r_K才等于精确凝聚残差t。内部恢复缺陷可经BᵀA⁻¹传播到边界，不能仅打印r_K或求解器内部的“reduced residual”。

记e=u*−û=(e_I,e_K)，则H e=r，故

e_K=S⁻¹t， e_I=A⁻¹r_I−A⁻¹B e_K。

这也是一般证明：从第一块消去e_I，再代入第二块。符号与@1澄清一致：整体未知量为u，不用内部x指代整体向量。

若已核验R_I≥‖r_I‖∞、R_K≥‖r_K‖∞，以及

H_A≥‖A⁻¹‖∞， H_S≥‖S⁻¹‖∞， α≥‖BᵀA⁻¹‖∞， β≥‖A⁻¹B‖∞，

可得 E_K=H_S(R_K+αR_I)，E_I=H_A R_I+βE_K，分别控制‖e_K‖∞与‖e_I‖∞。也可用α=‖Bᵀ‖∞H_A、β=H_A‖B‖∞，较保守。若有直接认证T≥‖t‖∞，可用H_S T代替边界界。未经认证的条件数估计不提供这些上界；界大表示不能保证，不等于证明实际错误大。

## 3. 使用近似局部逆时，实际解的是哪个系统？

给定固定m×m矩阵K（不假设K=A⁻¹，也不假设对称），定义

S̃=D−BᵀKB， b̃=g−BᵀKf， x̂=K(f−B ŷ)。

精确算术下直接得到

r_I=(I−AK)(f−B ŷ)， r_K=b̃−S̃ ŷ。

即使S̃ŷ=b̃精确成立，r_K=0仍可能r_I≠0；原系统精确凝聚残差是−BᵀA⁻¹r_I。只有核对原系统两块残差才能分辨。这里K必须是同一个固定线性映射；输入相关/不同rhs迭代停止、各worker不同缓存版本或矩阵B与f用不同K，不满足这组身份，须直接核对原H。浮点实现另加实际计算误差，不能拿本式抹去roundoff。

多worker且A真块对角时，可按已冻结局部A_k/B_k/f_k构造和汇总r_Ik的作用，边界共同D只计一次。若内部跨worker耦合存在，局部证书不能当完整H证书。复用局部K或分解时至少绑定原矩阵/partition/源项/精度/坐标版本；这只是数学消费者契约，并非已实现的通信或调度升级。

## 4. 线性消费者的对偶身份

全解误差大不必意味着某个指定观测错误大；反之只认证一个观测不能认证全解。令z解

S z=c_K−BᵀA⁻¹c_I， q=A⁻¹(c_I−Bz)。

由块方程H(q,z)=c以及H对称，得精确身份

J(u*)−J(û)=qᵀr_I+zᵀr_K。

因此若有逐块残差上界，|J误差|≤‖q‖₁R_I+‖z‖₁R_K。证明是cᵀe=(H(q,z))ᵀe=(q,z)ᵀr；不是经验拟合。目标量和rhs/矩阵一起固定时，才有这一对应。

对偶本身若仅得近似w，不能把wᵀr当精确误差。定义d=c−Hw；仍有

J误差=wᵀr+dᵀe。

若已认证R≥‖r‖∞，H_H≥‖H⁻¹‖∞，D_d≥‖d‖₁，则

|J误差|≤|wᵀr|+D_d H_H R。

若wᵀr是浮点计算值，应另加该点积误差界。上述一般推导不证明这些数值上界已经可计算或便宜；对偶多一次solve的费用也须计入总成本。非对称系统须解Hᵀw=c，不能沿用本条对称公式。

## 5. 物理映射与拒用

接地线性电阻网络：H为导纳（S），u电压（V），h/r注入电流（A），逆范数单位Ω，R H_H为V。c=(0,1)为无量纲坐标选择时J是边界电压，q/z单位Ω，qᵀr_I+zᵀr_K为V；这是严格线性映射。耗散功率uᵀHu是二次目标，不能当同一个线性J，需另推误差项。原导纳测量/舍入误差要与算术误差分别覆盖。

浮动Laplacian的常数gauge使绝对电位不唯一：必须先接地或限定兼容子空间及观测，不能用本条H⁻¹。电压差可能可识别，但不是默认所有观测都可识别。输入按不同量纲混合的范数、只看预处理后残差、缩放坐标后不映回原单位、估计FERR/因子误差替代消费者证书、非线性器件或attention输出，都不能直接认证。

## 6. 公开解析开发情境

以下题干不提示定理名称；均为手算与代数推导，非CPU/模型测试、非未见验收。

1. **日志说边界残差为零，是否可交付？** A=1,B=1,D=2,f=1,g=0，局部K=0，取ŷ=0,x̂=0，则S̃=2,b̃=0，r_K=0；但r_I=1，精确S=1,b=−1,t=−1。真实解x*=2,y*=−1。拒绝只用边界残差结案。α=β=H_A=H_S=1，界E_K=1,E_I=2恰取到。
2. **所有日志残差只有10⁻⁸，电压是否足够准？** H=diag(1,ε)，0<ε=10⁻⁸，h=(0,ε)，û=0。r=(0,ε)，真解(0,1)，误差1。H_H=ε⁻¹才给正确绝对界1；小残差不证明高精度，SPD本身没有统一条件数保证。
3. **某个消费者读数为零误差，能否说全解正确？** H=I₂，h=(0,1)，û=0，c=(1,0)。对偶(q,z)=(1,0)，观测误差0而全解误差1。只能交付这一固定观测；改成c=(0,1)后误差1，旧证书不能沿用。
4. **双节点接地网络恢复后，边界电压差多少？** H=[[2,−1],[−1,2]] S，h=(1,0) A，真解(2/3,1/3)V。û=(2/3+δ,1/3)V，δ=1/100 V，r=(−2δ,δ) A。A=2,B=−1,S=3/2，t=δ−(−1/2)(−2δ)=0，边界误差0而内部误差−δ。对c=(0,1)，z=2/3Ω,q=1/3Ω，q r_I+z r_K=0V。说明完整r_K非零也可由内部缺陷抵消；直接认证t比R_K+αR_I更紧。
5. **两节点漂浮电路零残差是否认证绝对电压？** H=[[1,−1],[−1,1]]，h=0，û=0与u*=a(1,1)都有零残差。绝对电压误差a无界，拒绝可逆前提；电压差观测(1,−1)在此例为零，但不能由此认证每个坐标。
6. **预处理器打印10⁻¹²，能否换成原系统R？** H=I₂，h=(1,0)，û=0，P=10⁻¹²I₂。‖Pr‖∞=10⁻¹²而‖r‖∞=1。须有P⁻¹上界或重新计算原残差；数值小只是缩放，不是误差改进。
