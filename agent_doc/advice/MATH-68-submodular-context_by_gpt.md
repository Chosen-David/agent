## 经典结论和自行展开的证明

来源：Nemhauser–Wolsey–Fisher, *An analysis of approximations for maximizing submodular set functions—I*, Mathematical Programming 14 (1978), 265–294；[原文](https://thibaut.horel.org/submodularity/papers/nemhauser1978.pdf)，§2 Proposition 2.1、§4 Theorem 4.2，印刷页280。以下是本轮自行写出的归一化短证明，不声称逐字复现其证明或完成形式化验证。

有限地面集 V，f:2^V→R≥0，f(∅)=0。要求单调：A⊆B⇒f(A)≤f(B)；子模：对 A⊆B、e∉B，Δ(e|A)≥Δ(e|B)，其中 Δ(e|S)=f(S∪{e})−f(S)。固定整数1≤k≤|V|，OPT=max_{|S|≤k}f(S)。所有元素成本均为一个单位；每步从剩余元素精确选取最大边际，S0=∅，执行k步，平局任意。

令O为最优集。单调性和逐项加入O\\S时的边际递减给出

\[
OPT\le f(S\cup O)\le f(S)+\sum_{e\in O\setminus S}\Delta(e\mid S)
\le f(S)+k\max_{e\notin S}\Delta(e\mid S).
\]

令 Dt=OPT−f(St)≥0（t≤k时St可行），a=1−1/k。最大边际≥Dt/k，所以 Dt+1≤aDt。递推得到

\[
f(S_k)\ge (1-a^k)OPT\ge(1-e^{-1})OPT.
\]

k=0只可选空集，不使用1/k；OPT=0时不计算质量比值。若最大剩余边际为0，可停止：上述不等式直接证明当前已最优。完整扫描且无提前停止时边际查询数为 kn−k(k−1)/2，n=|V|；这是查询次数，不是实际时间/token成本。

近似选择必须具体量化：第t步真实边际至少为最大真实边际−εt，εt≥0，则 Dt+1≤aDt+εt，故

\[
f(S_k)\ge (1-a^k)OPT-\sum_{t=0}^{k-1}a^{k-1-t}\epsilon_t.
\]

k=1的递推权重指数0取1。若所有本步边际估计有绝对误差≤ηt，选估计最大者只保证 εt=2ηt：最大真值≤对应估计+ηt≤被选估计+ηt≤被选真值+2ηt。普通相关度分数、均值误差或未经认证的LLM打分不是这个统一误差界。

## 一个真的子模代理目标

固定特征集合U，固定权重wu≥0，每条材料e有固定覆盖集Ce⊆U。令

\[
f(S)=\sum_{u\in\cup_{e\in S}C_e}w_u.
\]

新增e的边际是Ce中尚未覆盖特征的权重和。已选集扩大时未覆盖特征只能减少，因此单调、归一化、子模。这证明的是这个覆盖函数，不证明“真实任务成功率”也有这些性质。特征、权重或覆盖映射随已选集变化时必须重新检查，不能挪用固定目标定理。

公开正例：U={1,…,6}，单位权重，A={1,2,3,4}、B={1,2,5}、C={3,4,6}，k=2。贪心先A，再B或C，值5；最优B+C值6；5/6≥有限k下界3/4。贪心有保证但不是总最优。

## 三种表面相似的误用

1. **互补前提。** V={a,b,c}，k=2，0<ε<1，f(S)=1{a,b⊆S}+ε1{c∈S}。单调且归一化，但 Δ(b|∅)=0<Δ(b|{a})=1，违反子模。贪心先c、再任一a/b，值ε；最优{a,b}值1，比例可趋0。a是结论、b是必要前提时，覆盖代理不能认证推理质量。
2. **不同token成本。** 两项，小项成本ε、价值2ε，大项成本1、价值1，总预算1，0<ε<1/2。目标加性，甚至是子模；简单“价值/成本最高且能放下”先选小项后大项无法放下，值2ε，最优值1。此反例只针对这个简单密度算法，不针对有最佳单项比较/枚举的其他背包算法。按条目数的经典保证不能直接移植到token背包。
3. **非单调惩罚。** f(∅)=0，f({a})=f({b})=1，f({a,b})=0，k=2。这是非负子模函数，但不单调；强制贪心填满给0，而“至多2项”最优为1。加入冗余惩罚之后仍需重新核对单调性，不把另一算法/另一目标的保证抄过来。

## mandatory前提与准确比较对象

固定不可裁剪集合P，g(S)=f(P∪S)−f(P)，定义于V\\P；它归一化、单调、子模。若总单位预算K，r=K−|P|：|P|>K不可行，r=0无需选择，1≤r≤|V\\P|时可对g运行r步贪心。保证仅针对包含P、总大小≤K的最优集O_P：

\[
f(P\cup S_r)-f(P)\ge[1-(1-1/r)^r]\{f(O_P)-f(P)\}.
\]

不能与不受P限制的K项最优解混用。按实际token成本扣除P后仍是异质成本背包，以上基数定理不适用。把结论+假设+知识ID作为固定包，可以减少漏前提风险；包的覆盖并集仍子模，但包成本不同/依赖条件复杂时不能恢复单位预算结论。
