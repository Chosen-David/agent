# 有限时域输入能量、终端输出与可达性

稳定 ID：`candidate.finite-horizon-input-output-gain@1`；名称：有限时域强迫输入的终端增益与最小能量；版本1；核查日期2026-10-11。状态：经普通文档审核的探索候选，未进入 canonical corpus/Skill/生产行为。沿用按需知识入口，只读一个谱定理条目；候选导航见本轮 navigation.json。

## 对象、符号与适用条件

固定有限矩阵 A∈C^{n×n}, B∈C^{n×m}, C∈C^{p×n}，n,m,p正整数；T≥1为整数，E≥0有限。系统 x_{k+1}=Ax_k+Bu_k。所有范数是同一归一化坐标的欧氏范数，*为共轭转置；A^{T}在本文表示T次幂，绝非转置。模型无直接输入到输出的feedthrough项。状态初值任意，但所测的是终端输入贡献 y=C(x_T−A^{T}x_0)，不是完整Cx_T。U=(u_0,…,u_{T−1})按时间堆叠；预算是总平方范数 Σ||u_k||²≤E。没有逐步幅度/路径约束。定理不要求A稳定或全状态可控，时域有限即可。

定义 H_T=[CA^{T−1}B,…,CB]，W_T=Σ_{j=0}^{T−1} A^jBB*(A*)^j，G_T=CW_TC*=H_TH_T*≥0。

## 准确结论与可复核推导

**经典线性代数结论的本项目输出/复数/奇异情况推导**：

1. sup_{||U||²≤E}||y||²=E λ_max(G_T)。这是最坏输入终端贡献，不是每个输入的实际响应，也不是轨迹最大值。E=0或H_T=0时为0。
2. 目标d可达当且仅当d∈range(H_T)=range(G_T)。可达时最小总能量为d*G_T^†d，唯一最小范数输入U_min=H_T*G_T^†d；†表示Moore–Penrose伪逆。不可达时等式约束无解，最小能量记+∞，不得把有限的伪逆二次型当作可行代价。

展开递推得到x_T=A^{T}x_0+Σ A^{T−1−k}Bu_k，故y=H_TU，块乘法得到G_T。对H_T*H_T应用自伴谱定理，||H_TU||²≤λ_max(H_T*H_T)||U||²；两个乘积的非零谱相同（Hv≠0时把特征向量映过去），最大值等于λ_max(G_T)。H非零且E>0，取归一化最大右特征向量v，U=√E v达到等号；实数据可取实向量。此为一般证明，算例不承担证明责任。

对任意z，z*G_Tz=||H_T*z||²，因此kerG_T=kerH_T*，取正交补得rangeG_T=rangeH_T。若d在该空间，G_TG_T^†d=d，故H_TU_min=d。U_min属于rangeH_T*=(kerH_T)^⊥；任何可行U=U_min+v，v∈kerH_T，能量分解为||U_min||²+||v||²。再用G_T^†G_TG_T^†=G_T^†算得||U_min||²=d*G_T^†d。若d不在rangeG_T，GG†d只是投影，不能解原目标。

T=0另作空输入问题：输出贡献0，只有d=0可达；本卡不通过伪装正时域套用。初值不为0而关心总输出时，必须先把目标平移成d−CA^{T}x_0。

## 迁移映射与未成立的迁移

传感器例把归一化标定残差映为状态、注入误差映为输入、最终读数映为C、两次标定期限映为T，保留线性叠加、时序与总平方预算。可证伪预测：该固定模型下，任何预算4/5输入终端绝对值≤1，(.4,.8)恰达界；一旦发现模型一致且预算合规但超界，则前提/推导/实现至少一处有错。物理量必须先确定归一化尺度；未指定电阻、采样间隔等，平方范数不称焦耳能量。不主张守恒定律。

Agent 多轮误差汇聚只有经验证固定A/B/C、同一坐标、明确误差输入及总平方预算时才可映射。token、时间、会议文件数不能直接替代E；非线性/切换/适应性工具调用、未建模误差、局部线性化余项缺失时只能保存候选。未成立迁移：用此式决定真实Agent记忆清理、资源分配或安全停止；没有实测/可靠完整模型，拒绝接入生产。
