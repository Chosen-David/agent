# 可交换输入的线性聚合：平均投影与异构角色拒用

稳定ID：`candidate.intertwiner-averaging@1`；版本1，2026-10-12（Asia/Shanghai）核查。这是已有`math.reynolds-projection@1`在算子空间上的任务级补充，不新增Skill或canonical卡。数学结论为经典平均原理的直接推导，不声称原创定理。普通文档审核与真实Agent性能分别验收。

## 对象、表示与准确结论

G为非空有限群；V=Rⁿ、W=Rᵐ，n,m≥1。ρ:G→GL(V)、τ:G→GL(W)为精确线性表示，满足ρ(gh)=ρ(g)ρ(h)，τ同理。T:V→W是m×n实矩阵。定义完整均匀平均

Q(T)=|G|⁻¹Σ_g τ(g)Tρ(g)⁻¹。

定义交织空间E={S:Sρ(g)=τ(g)S，对所有g}。Q²=Q，rangeQ=E：它将任意线性映射投影到等变映射。标量输出τ=1为输入不变；输入输出都置换时是等变，不应混称输出不变。

若每个ρ(g)、τ(g)在所声明欧氏坐标中正交，Q还是Frobenius内积〈A,B〉=tr(AᵀB)下的正交投影。因此对每个S∈E，

||T−S||F²=||T−Q(T)||F²+||Q(T)−S||F²。

Q(T)是T到E的唯一最近矩阵；参数离对称子空间更近**不等于**真实任务更准。对非正交表示，幂等/等变仍成立，但原坐标Frobenius最近性一般不成立。更换成群不变度量须明确改变距离和物理缩放，不能暗中换范数。

若还给定随机(X,Y)∈V×W，对所有g有(ρ(g)X,τ(g)Y)与(X,Y)同分布；损失ℓ(a,y)可测、非负、对预测a凸且满足ℓ(τ(g)a,τ(g)y)=ℓ(a,y)，并且R(T)=Eℓ(TX,Y)<∞，则R(Q(T))≤R(T)。风险结论依赖**联合分布与损失**，不由参数投影单独推出；联合不变含标签/目标的对应，而不仅输入看上去相似。这条风险推论本身不额外要求表示正交，只要求上述损失不变；平方欧氏损失可由正交τ保证该条件。

这里没有非线性网络参数平均结论：矩阵平均在本线性映射类内，而平均网络参数通常不等于平均函数。若原可行矩阵集合非凸或不是作用L_g下不变，平均可能破坏稀疏性/离散约束。算子精确、有限、统一单位；浮点近似、抽样群元素、非均匀权重另验。

## 一般证明与可复核步骤

令L_g(T)=τ(g)Tρ(g)⁻¹。先核对顺序：
L_gL_h(T)=τ(g)τ(h)Tρ(h)⁻¹ρ(g)⁻¹=L_(gh)(T)，故L是Hom(V,W)上的线性表示。

由左乘h只置换全群求和，L_hQ=Q；Q(T)属于所有L_h的固定子空间。L_h(S)=S等价于Sρ(h)=τ(h)S；固定S有Q(S)=S。于是rangeQ=E且Q²=Q。这直接应用已有Reynolds平均，不需要假定G可交换。

正交ρ/τ时L_g保持Frobenius内积，L_g*=L_(g⁻¹)。逆元素置换全群，Q*=Q。幂等自伴投影的残差与E正交：〈T−QT,S−QT〉=0；平方范数展开给上述Pythagoras和唯一最近性。

风险推论：有限和的Jensen给
ℓ(Q(T)x,y)≤|G|⁻¹Σ_g ℓ(τ(g)Tρ(g)⁻¹x,y)
=|G|⁻¹Σ_g ℓ(Tρ(g)⁻¹x,τ(g)⁻¹y)。
第二步用损失联合不变；期望中用g⁻¹的联合分布不变性，每项期望都是R(T)。非负性与有限R确保合法，得到风险不增。若只能证明对某一固定公开样本集合闭合，可得到该集合经验风险结论，不能自动升为未来总体风险。

## 六个公开开发问题和反例

均已用于开发与普通复核；0未见测试。手算实例不替代一般证明，不计科学数值实验。

| 不提示定理名称的问题 | 对象、答案与拒用 |
|---|---|
| 两个相同类型读数交换槽位不应改变输出，旧权重[2,0]如何修正？ | G=C₂，ρ为交换S，τ=1，Q=[1,1]。对S₀=[1,1]，原参数距离平方2，新距离0；不据此承诺真实准确率。 |
| 两输入和两输出都随同交换，矩阵[[1,2],[3,4]]如何保持对应？ | ρ=τ=S，Q=(T+STS)/2=[[5/2,5/2],[5/2,5/2]]，与S交换。一般2×2交织矩阵为[[a,b],[b,a]]；此特殊T得到a=b，不代表所有等变矩阵必须四项相等。 |
| 变换[[1,2],[0,−1]]的平方是I，完整平均是否必为原坐标最近解？ | ρ为该非正交C₂表示，τ=1。行T=[1,0]有Q=[1,1]，固定行满足b=a。但原Frobenius最近固定行为[1/2,1/2]，距离平方1/2，小于Q的1。拒绝不满足正交条件的最近性。 |
| 给原槽位3/4、交换槽位1/4的权重，是否仍是精确投影？ | 对T=[2,0]得[3/2,1/2]，再平均得[5/4,3/4]，非幂等且不固定交换。完整均匀群平均条件失效。 |
| 目标始终为x1+x2，强制相同权重一定降低预测误差吗？ | X=(Z,0)，EZ²=1，Y=Z。T=[1,0]原平方风险0，Q=[1/2,1/2]风险1/4。目标函数对交换不变，但输入/标签联合分布不具有交换不变性；故拒绝总体风险结论。 |
| 三份特征，前两份同类可交换，第三份有不同可信职责，可以把三者平均吗？ | 只取交换前两槽位的C₂：T=[2,0,4]→[1,1,4]，第三权重保留。若擅取全S₃，变为[2,2,2]；输入(0,0,1)给4与2。不同职责并未证明全S₃目标/权限/分布对称，拒绝扩群。 |

单位：各被交换输入必须共享声明的特征尺度，输出变换必须保持对应意义；不同单位的原始量不能直接交换。有限群可很大，显式计算|G|项可能昂贵；本轮不声称推理零成本或token节省。

## 迁移映射和双索引

学科入口：群论与表示论→有限表示/交织空间；高等线性代数→Frobenius正交投影；统计决策→凸损失与联合分布不变。问题结构入口：输入重标号、输出对应变换、线性聚合、分块可交换、参数距离与预测风险分离。

具体模型映射：六题最后一例将固定三维数值报告特征映为V、固定线性聚合映为T、前两同类槽位重标号映为ρ(C₂)、标量结论不变映为τ=1。严格保留线性和该子群作用，公开可证伪预测是Q(T)x在交换前两槽位后完全相同，而第三槽位贡献仍为4x3。该模型内关系不是比喻；真实会议文本、LLM生成、来源可靠性和权限不是已验证的线性特征。

多AI应用只保留候选：同模型名称不证明报告联合可交换；主控/审稿/工具执行者的能力、权限、输入及可信等级不同，不能默认全角色置换。甚至线性聚合对槽位不变也不证明结论正确。实际应用要先指定目标、角色子群、数值特征/单位、联合数据和损失，再做同模型/工具/预算的未见检索与拒用对照；本轮未做，所以不改会议权重、生产入口或advice清理。
