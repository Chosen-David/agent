# 条件风险怎样组成任务链全程保证

稳定ID：`candidate.sequential-first-failure-budget@1`。2026-10-11，解析文档候选，非canonical知识卡/生产策略。关系：MATH79区分边际与路径；math.sequence-tv-coupling是两个完整轨迹分布的差界，本条控制单个过程首次失败概率；prob.conformal-policy-control@1说明群体期望校准不能直接升级逐历史证书。前置：有限概率、条件期望、事件并集。

## 数学对象、前提与结论

采用有限概率空间、有限整数T≥0，信息历史F_0⊆…⊆F_T。E_t∈F_t是第t步定义明确的失败事件；S_0=Ω，S_t=∩_{j≤t}E_j^c，D_t=S_{t-1}∩E_t为首次失败。S_{t-1}∈F_{t-1}，条件界在该事件上几乎处处成立；有限模型等价于每个正概率历史成立。过去执行、策略、动作选择、环境信息及此前是否失败包含在F_{t-1}。只在正概率历史讨论条件概率。

执行前预算a_t∈[0,1]是F_{t-1}可测量，即从当时可用信息选定。核心前提为在S_{t-1}上的每个相关历史，h_t=P(E_t|F_{t-1})≤a_t。预测器原始分数、校准总体均值、有限样本平均不能代替这个逐历史上界。

**确定性界。** 若a_t是预先固定的确定性数，则
P(至少一次失败)≤1-Π_{t=1}^T(1-a_t)≤min(1,Σa_t)。
不要求各步独立，也不要求固定策略；但全历史条件上界必须覆盖实际自适应策略。

**自适应支出界。** a_t可随执行前历史变动；若每个正概率完整路径上Σ_{t=1}^T a_t≤B，B为固定非负无量纲数，则
P(至少一次失败)≤min(1,B)。
不声称ΣE[a_t]≤B能证明每条路径预算可行，也不把Π(1-E[a_t])当随机预算版本。仅需控制总体概率时ΣE[a_t]≤B也足以给上述概率界，但它不提供逐路径额度约束。

T=0空积1、空和0，失败概率0；a_t=1使乘积界退化1；B≥1只给平凡界。初始已存在失败不在S_0=Ω模型内，须先把初始失败事件加入第0步及其预算，不能忽略它。

## 可复核证明

确定性a_t：P(S_t)=E[1_{S_{t-1}}(1-h_t)]≥(1-a_t)P(S_{t-1})；逐步归纳给P(S_T)≥Π(1-a_t)。有限非负a_t的乘积展开/归纳给1-Π(1-a_t)≤Σa_t。这里用的是条件上界，不是独立性。

自适应a_t：D_t互斥，故P(∪E_t)=ΣP(D_t)=ΣE[1_{S_{t-1}}h_t]≤E[Σ1_{S_{t-1}}a_t]≤E[Σa_t]≤B。每步有限条件期望等式来自对历史分区逐项求和；没有调用未经检查的可选停止定理，也不声称无限时域结论。

**真正无条件边际界仍有价值：** 若确实证明实际部署过程每步P(E_t)≤b_t，则union bound给P(∪E_t)≤min(1,Σb_t)，不要求条件风险界或独立。但只有这些边际不能使用更强的乘积界。校准分布上的平均loss若不是实际部署每步E_t概率，则连这个代入也不成立。

## 六个公开无定理名结构题与反例

1. 两步行动，在全部尚未失败的历史上每步失败概率≤.01。问全程风险：≤1-.99²=.0199，不是.01。独立Bernoulli(.01)给等号，仅作为可达例；一般证明不依赖独立。
2. 两个等概率互斥灾害区域各占.1，E1/E2分别对应它们，每步边际=.1，全程=.2。按边际乘积会给.19而失效；正确union界=.2。存活后第二步hazard为.1/.9，不能假报.1。
3. 历史类型C为bad的概率.01，失败当且仅当bad。群体风险=.01，但bad历史条件失败=1；若部署选择仅bad，实际失败概率=1。不能把群体校准分数冒充每段历史证书或转移后风险。原混合总体上的真实边际=.01仍正确，不反驳union bound。
4. 执行前已知公平分支C：C=0时a1=.5,a2=0；C=1时a1=0,a2=.5。在有预算的那步以概率.5失败，另一部无失败。每路径预算=.5，全程失败=.5；E[a1]=E[a2]=.25，1-(1-.25)²=.4375低估。随机预算只用均值乘积无效，自适应支出界B=.5正确。
5. 先允许风险.02的行动，再按其结果决定是否继续；每条路径后续执行前预算总和≤.03，则全程≤.05。停止决定必须在下一行动前作出，停止后设后续E为空、a=0；已发生失败不因停止撤销。安全停止不证明原任务全部完成，确认/反思/人工操作若也会失败须纳入事件模型。
6. 跨领域：设备检测的最多三次操作，每个存活历史条件失效界(.01,.02,.03)，故至少一次失效≤1-.99×.98×.97=.058906。单位为概率，不能拿温度/时间/经验故障频率直接当此证书；真实物理状态与机制、漂移和条件风险均未知。映射保留条件概率链，不认证真实设备。

这些是公开解析例与手算核验，非模型检索/未见测试/科学数值实验。第2/3/4例为不同前提失效见证，不能删掉拒用条件只保留结论。

## 迁移到多AI、多机任务链的候选接口

原问题：主AI根据已有结果选择下一个工具/机器/动作，担心整条链某次输出错误或数据传输失效。对应历史为完整任务/版本/证据/动作选择，E_t为事先定义的失败，a_t为覆盖该动作及历史的认证上界。真正保留的是有限事件与条件概率；AI“置信分数”不自动是h_t上界。

可证伪最小路径：固定失败定义、有限T、环境/策略版本；独立核验风险上界来源及适用历史；对照日志逐步检查执行前预算、每路径总额度与首次失败标签。改变任务、代理、机器、通信或干预路径使条件证书失效时暂缓应用。未来同模型/权限/可比预算测拒用、任务成功与成本，才决定是否接入。真实hazard证书、全路径预算账本、校准/数值包络和模型/GPU收益本轮均不存在，disposition=defer。

并行任务可将一个轮次E_t定义为该轮任一子任务失败；若各子任务在同一执行前历史下有认证条件界，其并集界可用，不能默认不同机器独立。内部相互影响和异步历史还需明确概率模型。本轮不实现调度器。所有硬权限、GUIDE、撤销和未完成要求独立生效，概率低不授予越权动作。
