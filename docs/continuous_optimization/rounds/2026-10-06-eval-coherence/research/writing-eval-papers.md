## 1. PaperRecon

**Bibliography and scope.** Atsuyuki Miyai, Mashiro Toyooka, Zaiying Zhao, Kenta Watanabe, Toshihiko Yamasaki, Kiyoharu Aizawa. *Paper Reconstruction Evaluation: Evaluating Presentation and Hallucination in AI-written Papers*. arXiv2604.01128v1, 2026-04-01. Read main §§1–6, physical pp1–10; Appendix A/B pp14–25 including overview/rubric/writer/judge prompts; selected annotated generated-method examples pp37–39 were encountered and read, but Appendix C is not claimed as fully read. Physically rendered p9 inspected for Table4, human validation and limitations.

**Method and result interpretation.** Input contains original figures with shortened captions, original tables, bibliographic entries enriched with abstracts, optional code and a fixed section skeleton. Mean short overview463 words; long overview1492. Thus this primarily tests reconstruction under curated resources, not new scientific contribution, literature retrieval, free outline design or diagram synthesis. Rubrics are GPT5.4-generated and author-reviewed; text/table/figure items become section scores. A claim is supported, neutral or contradictory, with a coding-agent second pass only for flagged contradictions. “Absent from source” is explicitly not automatically contradictory.

Human presentation validation is72 pairwise comparisons from12 papers, three reviewers24 pairs each; Kendall tau-b .578. It is not72 independent source papers or a repeated multi-reviewer reliability estimate. The97 flagged claims checked for precision do not reveal undetected fabrication. A plausible unsupported scientific claim could remain neutral; local scientific admissibility still needs positive support. The Conclusion section is excluded from claim/rubric evaluation, so adopting this protocol unchanged could miss the exact place where negative results become overstated conclusions. No equal-cost comparison or precise agent token/time cost is supplied. Table4 is a small input-information ablation, not proof that verbose handoffs always help. Source table values qualify abstract wording: GPT5 has10.2 contradictions, and Teams9.8 is below10, so broad “Codex≈3 / Claude>10” is not universal across configurations.

**WE-PR-01 — test, not implemented.** Candidate source files: `workflows/paper_delivery_contract.md`, `workflows/figure_shared.md`, `evals/rubric.json`. Preserve the existing private audit material boundary. At the diagram→caption→paper handoff, give the writer a small scientific brief: research question, mechanism, decisive evidence, panel/edge meaning, result scope and unresolved facts. Grade content coverage, scientific narrative and evidence fidelity separately; include Abstract and Conclusion. Minimal experiment: same three different scientific topics and same factual inputs, old handoff vs brief; freeze drafts, independently read full outputs and compare concrete omissions, unsupported statements, topology claims, and whether the main text explains a scientific argument rather than audit history. Include a correct short draft and a polished fabrication as controls. Cost estimate: six writing runs plus six independent reads; measure tokens/time rather than asserting savings. Adopt only if narrative improves without fidelity regressions; three topics remain a pilot, not a general quality rate.

## 2. data-to-paper

**Bibliography and scope.** Tal Ifargan, Lukas Hafner, Maor Kern, Ori Alcalay, Roy Kishony. *Autonomous LLM-driven research from data to human-verifiable research papers*. arXiv2404.17605v1, 2024-04-24. Read pp1–16 (all main text and Methods), Table1 and Figures1–4 pp22–27, FiguresS1–S8 with captions/examples pp28–38. Rendered p27/Fig4 inspected. External supplementary TablesS1–S9, per-run manuscripts and repositories were not fully retrieved/read; they are not a second evidence source in this note.

**Mechanism and failures.** Seventeen steps produce typed artifacts from a designated subset of prior products. Coding checks separately cover static structure, execution, package-specific constraints and requested outputs. Numerically traceable prose uses labels and computable formulas, assembled as links into a Notes appendix and then tables, outputs and code. This catches provenance/formatting errors; it does not establish that the chosen statistical question or interpretation is valid. The Methods explicitly say earlier manuscripts lack this later hyperlink feature, so the reported original success fraction is not a controlled estimate of its benefit. No isolated ablation of provenance or reviewer role inversion is reported.

The fixed-goal treatment-policy case deliberately contains positive treatment-choice and null outcome findings. All ten analyses were correct, yet two manuscripts made interpretation errors, including one affecting the overall conclusion. Complex model-comparison tasks fail much more often; additional detail in goal/data descriptions changes error rates (FigS8). Three copilot successes are a tiny, selected demonstration. Dataset descriptions were iteratively tuned using pilots;50 extra task-breadth runs stopped after Title/Abstract to save calls. Claims of autonomous80–90% reliability must retain these conditions. Generic phrasing, inflated novelty and poor citations remain despite canonical paper organization; these are directly relevant to the user's technical-report-like writing complaint, but not a controlled experiment in journal style.

**WE-DP-01 — test, not implemented.** Candidate source files: `workflows/paper_delivery_contract.md`, `workflows/research_workflow.md`. Extend the existing private claim/evidence map only if a gap remains after reading actual consumers: pair each key result with its scientific interpretation and allowed scope, including null, adverse, conflicting and missing results. Keep provenance identifiers outside manuscript prose unless scientifically useful. Minimal experiment: within the three-topic writing comparison, include a result with a null effect, a metric trade-off and a scoped microbenchmark. Ask an independent reader to identify whether captions, Results, Abstract and Conclusion preserve each limitation and whether a code-derived number still supports the verbal claim. Cost: one additional result-interpretation pass per draft; no full17-step platform migration. Reject aborting all useful drafting merely because one value is unknown: retain the current bounded working-paper/blocker policy.

## 3. PaperBench

**Bibliography and scope.** Giulio Starace, Oliver Jaffe, Dane Sherburn, James Aung, Chan Jun Shern (PDF author order/name form), Leon Maksin, Rachel Dias, Evan Mays, Benjamin Kinsella, Wyatt Thompson, Johannes Heidecke, Amelia Glaese, Tejal Patwardhan. *PaperBench: Evaluating AI’s Ability to Replicate AI Research*. arXiv2504.01848v1, 2025-04-02. Read §§1–8 pp1–10; AppendicesA–I.1 pp13–19, plus Tables10–13 pp20–21. Rendered p19/Fig6/Table9 inspected. Remaining per-model tables and full prompt panels pp22–30 not claimed read; relevant scaffold method is described in F. Bibliography not systematically read.

**What is useful.** A rubric leaf needs a specific outcome; code existence, executed operation and reproduced result consume different evidence. The author clarifications/addendum are essential: an apparently exact rubric can still encode wrong task facts. Fresh execution creates separate evidence before result grading. JudgeEval tests the judge itself against expert labels rather than treating a second agent's agreement as ground truth. Despite this, a judge error rate remains, and averaging partial credit is a benchmark signal rather than fulfillment of all user requirements.

Main runs use one A10,12-hour allowance, typically three seeds per paper, original repositories disallowed. Table9 qualifies that o1 IterativeAgent and Gemini BasicAgent standard errors use two seeds. Human comparison uses selected best-of-three attempts and a three-paper48-hour subset, not an equal-budget universal human/model result. Table8's .72 code-development F1 and .94 result-match F1 show criterion-specific accuracy. Table3/8 differ .78/.77 for o1-mini overall: retain table-local values rather than manufacturing reconciled precision. Historical $66 grading and ~$400 rollout are authors' estimates; no current pricing inference. AppendixH/Fig6 reports one rice submission whose estimated score changes .93→.48→.30→.27→.25 with pruning depth1/2/3/4/full; human reference lies below. Tenfold cheaper depth3 is neither an accuracy guarantee nor evidence for this repository. Authors explicitly observed unsatisfactory pruning cases.

**WE-PB-01 — test within existing CO-020, not implemented.** Candidate source files: `scripts/agent_eval_pipeline.py`, `evals/rubric.json`. Existing prepare/verify already freeze task/rubric hashes and validate exact case sets; independent grader identity also already exists. The missing hypothesis is factual/semantic calibration of that actual grading path. Minimal experiment: reuse the two old incorrect factual cases and two corrected variants; add independently defensible equivalent wording plus a polished but false result. Hold grader/model/prompt fixed and report false rejection and false acceptance separately before/after any narrow factual preflight. Cost: six small grading cases per condition plus a root review of references; no GPU or PaperBench installation. Reject substituting a new generic score for mandatory TASK requirements, and reject node pruning until omission controls show non-degradation.

## 4. SciCoQA

**Bibliography and scope.** Tim Baumgärtner and Iryna Gurevych. *SciCoQA: Quality Assurance for Scientific Paper–Code Alignment*. ACL2026 Long Papers pp38740–38770, conference dates July2–7; fixed proceedings PDF, DOI10.18653/v1/2026.acl-long.1795, arXiv family2601.12910. Read §§1–8 physical pp1–10 and AppendicesA–F physical pp15–31; visually inspected physical pp9/21 (printed38748/38760), confirming Tables2/8. The preprint's81+530 figures and45.7% result are obsolete for this pinned proceedings artifact; do not mix versions.

**Method and qualifications.** Real records come from GitHub/reproducibility reports, manually filtered then verified/rephrased with models; versioned paper and code are pinned to reporting dates. Synthetic records introduce small conceptual changes without obvious bug comments. Default configurable differences and routine engineering details are excluded. Judge calibration uses1,039 annotated predictions with143 matches, obtained from top-three embedding-similar outputs for20 defects; this is not a random exhaustively labelled population of all predictions. A second judge agrees strongly with the first yet has only70.0% F1 against humans; agreement is not accuracy.

Code-only ablation, input-length and recent-publication analyses support testing access to actual scientific evidence. However context-length bins are observational and confounded by repository/domain complexity; they do not prove shortening arbitrary context fixes reasoning. Images are omitted by preprocessing, leaving captions, so this paper directly tests text–code consistency, not visual diagram verification. Evidence for transferring the taxonomy to diagrams is a local hypothesis.

Preserve two source tensions: mainTable2 and appendixTable8 both describe129 pooled defects but give different GPT5 P/R/F1 (88.0/51.2/64.7 versus84.1/63.6/72.4). AppendixC.6 specifies matching any available phrasing, but the text does not fully reconcile the two tables; record them separately, do not average. AppendixF.6 says missing implementation is outside scope while main taxonomy includes Code Omissions. The distinction may be an entire missing component versus a missing method step, but that is an interpretation requiring explicit local definitions. Pool-contributing models have a structural advantage; residual misses do not prove the complete inventory is known. GPU count/context sizes are given, but no total inference cost or runtime is established.

**WE-SQ-01 — test, not implemented.** Candidate source files: `workflows/figure_shared.md`, `workflows/paper_delivery_contract.md`, `evals/rubric.json`. Build a small consistent artifact bundle per topic containing a method description, meaningful operations/edges, caption and actual code/specification where present. Inject one material mismatch at a time: reversed data-flow, omitted branch, caption claiming implemented behavior when only proposed, metric averaging changed, or adverse result omitted from conclusion. Include clean equivalences: variable renaming, node repositioning and a configurable default that still matches the reported run. Minimal experiment: three bundles × one clean + two defective variants, independent reference annotation, frozen consumer review; record defect recall AND false accusations with explicit source locations. Estimated cost: nine bounded read-only checks per compared workflow. Adopt only after zero new false accusations and improved detection on this fixed pilot; expand before broad claims. A clean detector response remains “no issue found within reviewed scope,” not “scientifically correct.”

## Cross-paper consequence for the current task

The proposed chain is scientific evidence → mechanism/figure meaning → caption → paper argument, with private verification records supporting it. Hashes demonstrate artifact identity; structural checks demonstrate interface completeness; execution shows that specified code ran; independent source reading supports scientific meaning. None substitutes for the others. The same applies to writing: clear prose and a strong research argument are separate from provenance hygiene. Existing `paper_delivery_contract.md` already makes this distinction, so measure the real writer/consumer behavior before adding more prose requirements.

No runtime was installed, no private manuscript was copied, no upstream models or benchmarks were run, and no implementation/global ledger/TASK files were changed by this reader. Proposed candidates remain test-only. Root owns deduplication, final ten-paper synthesis, TASK acceptance and any implementation decision.
