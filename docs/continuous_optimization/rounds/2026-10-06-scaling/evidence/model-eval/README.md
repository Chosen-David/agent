## Process, comparison and limits

Each start receipt binds the actual `collaboration.spawn_agent` returned worker name and `fork_turns=none`. The independent controller inspected actual collected bytes and source, computed separate numerical checks, ran requested commands through an observable proxy, and opened final images/PDF-page renders. Parent independently reread key outputs and viewed PDF/mixed/data/diagram artifacts. Workers were not given the grading material. Receipt completions are controller transcriptions of observed messages, not complete exported transcripts or cryptographic attestation. Direct worker reads/writes and any worker-only process receipts are not independently exported tool traces. Shared filesystem/context separation is not an OS security sandbox.

The source/task/input/rubric hashes and identical adapter metadata for the two code-reading trials are checked in `paired-code-reading.json`. Both actual tasks passed. Exact model identity, seed, tokens and cost remain **unknown**; this does not establish a fair repeated model A/B, a success-rate gain, research quality, aesthetic improvement or system cost/latency benefit. Program scaling benchmarks are separately reported by the parent; model-task execution time here is not a benchmark. Domain fixtures are synthetic and clearly labeled; real backend/server/tmux/cloud memory, online travel information and production deployment were not integrated or tested. Offline HTML structure/arithmetic was checked; browser interaction was not tested. Diagram physical printing and venue compliance remain unverified.
