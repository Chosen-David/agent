# 科研与数据可视化：4 篇原始论文阅读记录

阅读日期：2026-10-06。与现有 `papers.json` 按 arXiv ID 去重，以下 4 篇均为新增；固定读取 v1，不能称为最新版本综述。原始 PDF 已下载并经文字提取阅读，重要页另外渲染查看；哈希、作者和精确范围见相邻 JSON。本记录不是所有附录逐页审稿，也没有复现论文的在线模型实验。

## 1. The AI Scientist（2408.06292v1，2024-08-12）

原文：https://arxiv.org/pdf/2408.06292v1 。作者 Chris Lu、Cong Lu、Robert Tjarko Lange、Jakob Foerster、Jeff Clune、David Ha。

**论文观察。** §3 从可运行小规模 baseline 模板出发，依次生成 idea、运行实验并记实验日志、绘图和写作；失败最多修复四次，实验迭代有上限。§4 表1 的校准 reviewer 在500篇 ICLR 2022论文上 balanced accuracy 为0.65±0.04；人类参照来自另一会议实验，不是同一批盲测。§5 PDF p10 有把 KL 0.090→0.093 写成“改善”的负结果误读；§6.2、§8 记录未来 token 泄漏、指标变更后错误比较、幻觉实验及不能看图。§6 实际并行版本没有等 reviewer 反馈回填才生成下个 idea，不能把闭环长期自我进步当已验证结果。

**本库候选 RV-01（工程推论）。** 在 `workflows/research_workflow.md`、`workflows/experiment_execution_contract.md` 和主 AI 验收入口，把“任务完成”和“假设被支持”分开。每个结果绑定 task/source revision、metric name/direction/unit、数据拆分、代码/config 指纹、baseline run；同一脚本由参数切换变体。先复现 TASK baseline，再用独立 run/branch 改一项假设。若定义改变、已泄漏或用户目标纠正，原日志保留，但从目标支持证据中撤下；报告允许 refuted/inconclusive。不沿用论文“评分高即科研成功”的归档条件。

**最小实验。** 冻结12个小案例：低优指标变差、单位变化、拆分泄漏、参数量变化、正确负结果等；比较旧验收与候选对错误成功的检出率、正确负结果保留率、开销；所有失败计入分母。这个12只是本库拟定的工程 fixture 数量，不是论文实验。

## 2. Agent Laboratory（2501.04227v1，2025-01-08）

原文：https://arxiv.org/pdf/2501.04227v1 。v1 作者不含后来 v2 添加的 Michael Moor，完整作者见 JSON。

**论文观察。** §3 把文献、实验、解释和写作分阶段，co-pilot 允许每阶段反馈后重做。mle-solver 通常用 LLM 给代码和输出评分；§4.4 的 MLE-Bench 测试另用 dev 分数筛选，最后测独立 test，不能混同两种评分。§4.1.1 / 图6：自动总评6.1/10，人评3.8/10，15篇自主论文由10名博士生各评3篇。§4.2.2 co-pilot 外部总评4.38，比自主平均高0.58，但贡献增幅很小。§5 记录编造实验、0%准确率未修复、仓库管理不足；成本比较受任务、模型及口径限制。

**本库候选 RV-02（工程推论）。** `workflows/research_workflow.md` 交接中增加“当前用户意图版本—实际完成—偏离—下一验证”对照；将 code-organization 的运行索引交给报告作者，只让其引用有 run receipt 的数值。反馈回合形成 correction，影响依赖链而非只在下一段 prompt 说“记得改”。专业 reviewer 必须看到证据/日志，作者自评只做候选意见；用户未回复可按既有预算继续 baseline，不自动要求每阶段等待。

**最小实验。** 同一冻结任务集按阶段注入一次用户纠正，评估修正后错误配置调用次数、错误数据被引用次数、重新执行成本及无关任务保留率。人评与自动分数分别报告，不把两者均值包装成质量。

## 3. MatPlotAgent（2402.11453v1，2024-02-18）

原文：https://arxiv.org/pdf/2402.11453v1 。完整13名作者见 JSON。

**论文观察。** §4 将需求展开、代码生成/最多三轮调试、对渲染图的视觉反馈分开。100个人工核验任务上的表1：GPT-4 48.86→61.16；但 CodeLlama34B 16.54→14.18，提升并不普遍。表2去掉 visual feedback 后 GPT-4 为53.44。图4视觉查看可见边缘分布、标签和布局修复。§3.2 的人评相关性基于100次抽取25例后的均值相关，不是每张图的准确性证明。§8 承认领域覆盖限制，生成图相似度也不等于主张科学正确。

**本库候选 RV-03（工程推论）。** 复用 `workflows/data_visualization_workflow.md`、`scripts/data_visualization_checks.py` 已有数值保真和独立角色检查，不再增加一个总指挥。将图的 input hash、实际绘制数组/聚合协议、render hash、目标物理尺寸与视觉读图回执一起冻结；反馈只改声明可变的设计项，最多三轮且可退回最佳已验证版本。视觉建议导致数据变化时转回分析纠错流程，不能作为 polish 自动通过。

**最小实验。** 6个独立数据集各生成 before/after，包含长标签、密集面板、中文与不确定性。先对数组、分组、尺度、标注执行等价检查，再随机隐藏顺序由独立读者评读图正确率、遮挡、层级、可访问性、偏好；保留每例失败和无改善。没有独立读图/线上模型时只报告机械检查通过，不能说审美已提升。

## 4. ChartMimic（2406.09961v1，2024-06-14）

原文：https://arxiv.org/pdf/2406.09961v1 ；HTML：https://arxiv.org/html/2406.09961v1 。完整14名作者见 JSON。

**论文观察。** §2 区分参考图重建与替换数据重建；1000个三元组、500个原型，评价分高层图像相似度和执行采集的 text/layout/type/color。§4.2 表5 GPT-4V Direct 71.4，SelfRevision 68.3，显示自我修改可能变差。§4.3 / 附录E 的1200图、每图三名评者，低层与人评相关0.7538，高层0.6942。附录C.1 的“data”维度主要看趋势/组数，不能保证精确数值。v1 §3.2叙述部分与表3/4有数值不一致，本文不复用有冲突的总榜差值。

**本库候选 RV-04（工程推论）。** `scripts/data_visualization_checks.py` 的字段/文件声明检查与实际图像评审分工保持明确；增加可复用 figure semantics sidecar（series、x/y值、units、transform、error定义）供独立数值验收，不以“能执行”“配色类似”“CSV未改”替代数据正确。设计分按可读性、任务匹配和风格一致性分别报告；同一变量跨图稳定映射但不强制临摹陌生领域风格。

**最小实验。** 配对测三种修改：合法 typography、误换序列映射、静默重聚合。期望只第一种通过数值门；盲评能给美观偏好而不能越过错误门。sidecar 由可信数据层导出并重新计算核对，不能只相信绘图agent自己填写。

## 采用边界与下一步

这些论文支持的是可借鉴的机制和常见失效模式，不是本库现已获得同样幅度的科研/审美提升。当前仓库已有 baseline、负结果、视觉反馈、独立角色、immutable run 的大部分文字要求；有价值的增量是纠正传播、可核验的数值/产物关联和冻结的独立对照。

优先级建议：先落地 RV-01/RV-02 的证据有效性机制；将 RV-03/RV-04 作为已有图表验收的明确配对实验协议。参数脚本复用已有 `plugins/research-assistant/skills/research-implement-optimize/scripts/experiment.py` 或项目真实 runner；该通用入口目前只是CPU fixture，不能冒充真实模型实验。避免为这四篇另造一套执行器、报告目录与agent。
