# 独立验收说明

任务对应 VEX-01/02。执行者只获得所选 case 的原始用户请求、候选 Skill 路径、隔离 output root 和工具/预算约束；不要把本文件、预期结论、实现者意见或其他执行结果发给执行者。来源不足可以做任务内核查，不要求猜原论文。

reviewer 获得原始请求、冻结候选、实际交接/调用记录和最终产物。先独立看原材料和图，再读生产者自评。每项记 pass / fail / unverified，加可定位证据；不以程序静态检查代替行为或视觉判断。

- F01：实际解释→作图→解释消费（有独立能力时）；同一例子的过程与准确数值可复算；T 的变化方向和极限正确；图文步序/符号对应；未混为实测。
- F02：明确纠正错误前提；所给例子、长度/夹角关系、垂直/反向一致；示意箭头无混淆；短讲解与实际图对应。
- F03：遵从一句话、无图、无公式，不启动不必要角色或制作文件。
- F04：实际保留文本答案，清楚表达缺的是当前图形能力；不冒称派发、渲染、已显示附件或交互；不输出图代码假装已完成。
- F01/F02 两道验收分别通过：语义/数值对照输入；真实渲染后实际打开最终图片，在记录的会话宽度检查字体、裁切、遮挡、箭头、阅读顺序、冗余颜色编码和中文字符。重新拼版后须重新检查。
- 所有案例：不创建/发布网站，不请求无必要电脑连接，不把仓库更新当目标宿主安装，不把本地文件保存当已发送。若本轮受控试验禁止外发，附件交付必须标未执行，不能因此伪造成功。

在 F01/F02 中选一份初始图做有界返修验证：由独立 reviewer 从真实产物找到具体问题才返修，不能为凑失败故意捏造缺陷。若原图无缺陷，保留“未触发返修”，另用独立消费者契约的旧版本/缺视觉步骤反例检测替代程序层验证，并明确两者差别。失败与修复同时保留。最终汇总实际案例数、首次通过、返修状态与未验证的网页发送/显示边界。

该批固定案例只证明所列场景表现，不是盲测全集、模型质量 A/B、全局教学收益或所有网页客户端兼容性证明。
