## 交付行为

解释方先短答，图有帮助或用户要求时才作图；按同一小例子从直觉、过程到精确/边界推进，稳定 step/panel 对齐。作图方返回真实主源/预览、caption/alt text、语义数值检查与实际视觉观察，解释方读取后整合成简洁会话回答。

网页优先使用真实支持的图片附件；只在有交互能力且参数变化有教学价值时用现有组件。无独立模型、无渲染、无图片查看和无附件通道分别降级。不建网站，不把 Mermaid/HTML/SVG 源码当作已显示图片。

## 验证与边界

- `tests/test_visual_explanation.py`：共享包分发/链接闭合；实际现有 handoff API 的正确交接、缺视觉步骤、未执行检查、图片变更、解释版本变更反例。它只能证明结构和文件完整性，不能证实图好看或科学正确。
- `cases.json`：四个有界、无答案泄漏的实际角色请求；`review.md`：独立审阅标准，与执行者材料分开。
- 当前尚未在本报告记录真实模型结果、附件发送、目标网页显示、安装生效或生产教学收益。程序测试通过后仍需实际读图和角色消费验证。

源文件和现有行为是接口证据；本轮没有提出教学效率或性能定量主张，因此不新增研究综述或用论文引用替代真实产物检查。
