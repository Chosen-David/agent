按常用定义 softmax(logits / T)，T 越大，概率分布越平，最高分的优势越小，但大小顺序不变。

logits = [2, 1, 0]，按这个顺序得到：
- T = 0.5：[86.68%, 11.73%, 1.59%]
- T = 1：[66.52%, 24.47%, 9.00%]
- T = 2：[50.65%, 30.72%, 18.63%]

原因是先除以 T：这三组实际输入分别是 [4, 2, 0]、[2, 1, 0]、[1, 0.5, 0]，差距越小，取指数后最大项的优势也越小。T 趋于无穷大时，三项都趋于 1/3；T 趋于 0 的正侧时，本例趋于 [1, 0, 0]。

图是按公式计算的教学例子；百分比保留两位小数，显示值相加可能差 0.01%。
