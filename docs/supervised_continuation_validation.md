# 监督续跑协议：实现与验证边界

日期：2026-10-03 UTC。初始基线 `db19c5f117070d1451e65a089f2f4d768362ac62`，发布前需合并同仓库并发变更并复核。

## 设计判断

用户的新指令修订了原先一律等待替代方案对齐的默认行为，但仅在已有授权任务链、真实监督触发和未答复决定的场景生效。目的合理：减少低风险细节阻塞，又先完成用户路线、保留公平比较和回退路径。

风险在于把“迟迟没答”错误解释成新权限，或用未经验证的 B 覆盖 A。因此实现明确：没有任意等待时长；没有新增监督服务；沉默不批准显式等待/停止、付费/隐私/发布等受控动作；参数选择只在现有实验授权与资源上限内。原反思门禁在其他场景保留。

“确定更好”落实为事先声明的主要改进阈值、全部必要非退化/硬约束通过、完整可复现证据及回滚。未测、噪声、取舍或 inconclusive 均保留 A，不把局部收益包装成所有可能指标都改善。
