# 中心化协方差与可合并统计量（2026-10-07）

本轮增加的能力是：识别原点二阶矩和中心协方差的差异，正确合并分块统计量，区分精确代数、统计前提与浮点误差，并在已有均值/二阶矩误差事件上推导中心化误差桥。没有新增 Skill、生产代码或 SGLang 改动。

检索日期为2026-10-07，实际版本/日期、阅读范围与PDF哈希见 [sources.json](sources.json)。本轮筛选 [Reichel 2605.00247v1](https://arxiv.org/abs/2605.00247v1)（2026-04-30）和 [Xu等 2609.04418v1](https://arxiv.org/abs/2609.04418v1)（2026-09-03），均为预印本，正式发表状态未核验。只核查相关部分，不声称全文审定或实验复现。

## 推导与迁移

worker共享同一坐标/单位/预处理，处理不重叠且不遗漏的分区，只发送计数n、均值m、散布S。两个非空分区合并时：

\[
S=S_A+S_B+\frac{n_A n_B}{n_A+n_B}(m_B-m_A)(m_B-m_A)^\top.
\]

最后一项是组间变化，不能省略。精确算术下合并等于集中计算，交换、结合且空状态为单位元；不要求iid，但不能由此推断独立采样、幂等重试或总体覆盖。n分母与n−1分母、空分区、单观测、坐标改变和权重各有边界。

对已有可靠的二阶矩误差ε_M与均值误差η，同一事件内中心协方差误差至多ε_M+(‖m‖+‖µ‖)η。若使用围绕真实µ的经验矩阵，另一界是ε_c+η²；两种ε对应不同对象，不能互换。相关方向的下游保证仍需谱隙，概率事件需另证。

跨领域例子为同标定温度测量：平移不改变中心散布，尺度变换平方作用于散布；单位是℃²。没有真实传感器实验。真实worker通信建议只保留为候选：用二进制工件引用传递统计量，携带分区ID和版本；对任意文本、token身份、时序或自回归状态并不充分。

一个拒用反例是：iid均匀取0、2，总体方差1；n=2的无偏样本方差只能为0或2。若用同一完整batch估计作参考，误差分数全为0，却无法覆盖总体方差。它否定“替代随机参考后无条件继承总体覆盖”的迁移，不否定已知真实总体参考下的固定时刻论证。
