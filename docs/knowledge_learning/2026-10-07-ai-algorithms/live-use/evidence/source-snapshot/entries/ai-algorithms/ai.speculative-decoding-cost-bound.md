# 推测解码：接受前缀尾和与成本盈亏条件

## 问题触发

“接受率高”“draft 更小”“一次验证多个 token”分别不足以证明延迟下降。先问接受率指单个候选、条件深度还是整棵树，再问验证、草拟与管理开销如何随形状和负载变化。

## 前提和精确结论

### 已知单提议接受率

对残差校正条目中的同一前缀、实际归一化 p,q，单候选接受率 α(h)=Σx min(p(x|h),q(x|h))=1−TV(p,q)，其中 TV=½Σx|p−q|。这是单次从 q 抽样并校正的概率恒等式；不直接等于任意树 verifier 的整轮接受比例。

### 本条推导：去掉独立性假设的前缀尾和

固定 draft horizon γ，A_i 表示第 i 个草稿通过正确核验，N 是连续接受前缀长度。一轮输出 L=N+1，包含拒绝补偿或全接受后的 bonus，暂不截断 EOS/最大长度。则

E[L] = 1 + Σ(i=1..γ) P(A_1∩…∩A_i)。

若 b_i=P(A_i | A_1∩…∩A_(i−1))，到达概率为零之后的项取零，则 E[L]=1+Σ(i=1..γ)Π(j=1..i)b_j。这是条件概率链式法则，不要求各位置接受独立。不同前缀的平均 α 不能自动取代这些 b_i。

### 已知理想化公式及本条成本推广

若到达每个深度后的条件接受概率均为同一个 α，则 E[L]=Σ(i=0..γ)α^i；α<1 时为 (1−α^(γ+1))/(1−α)，α=1 时为 γ+1。

以公平基线每 token 耗时 T 为单位，设一轮成本 C/T=γc+v(γ)+o(γ)，分别表示串行 draft、目标验证、其他开销。固定轮成本时，长序列平均速度比为 S=E[L]/(γc+v+o)，严格加速当且仅当 E[L]>γc+v+o。若轮成本随机，需要满足相应稳定/遍历或再生条件后比较 E[L]/E[C] 的长期 reward rate，不能用 E[L/C] 代替。这里不是对任意非平稳服务流的吞吐量定理。

原论文的理想化成本是 v=1、o=0、固定 c。在此模型且固定 α 下，存在正整数 γ 获得 S>1，当且仅当 α>c：γ=1 给充分性；因为 Σ(i=1..γ)α^i≤γα，α≤c 时任何 γ 都不能严格获益。α>c 不是含额外验证开销时的通用阈值。

## 推导范围

对整数 N∈[0,γ]，逐点有 N=Σ(i=1..γ)1{N≥i}，取期望就是尾和公式。单候选接受率由 Σq·min(1,p/q) 得到；概率质量重叠与 TV 的恒等式给出第二种写法。成本式是已定义的同口径成本模型；真实 c、v、o 和上下文分布必须测量，不能用模型参数量替代。

## 可复算正负例（本条构造，不是性能测量）

1. α=4/5，γ=4，c=1/10：E[L]=2101/625=3.3616。v=1、o=0 时 S=2.401142857…；若同一接受行为下 v=4，则 S=0.764，反而更慢。
2. γ=2，潜在接受事件边际各为 1/2：完全同成同败时 E[L]=2；独立时 7/4；互斥时 3/2。仅一个“平均接受率 50%”不能辨别三者。潜在事件可定义在预生成的完整草稿上，不代表拒绝后仍提交后续 token。
3. α=1/2、c=1/10、v=1、o=0：γ=1 时 S=15/11>1；γ=20 时 S<2/3。延长 draft 可能把收益变成亏损。
4. α=c=1/5 时 γ=1 仅打平，γ>1 更差；α=1 的端点不能直接代入 0/0 的几何商式。

## 树、MTP 与实测外推的负例

- 树有 K 个节点不意味着一轮发出 K+1 个 token；输出是一条经核验的前缀，验证成本与形状、mask、内存和 batch 有关。使用实测 L 与 C，或为特定树策略另建模型。
- MTP 多头命中率、整棵树命中率与单提议 α(h) 不是同一个量；除非重建了实际条件分布和相应事件，不能塞入链式几何公式。
- greedy 对齐不能代替随机采样准确性；随机分布不变也不推出低延迟，更不推出高 batch 吞吐量提高。
- 在不同目标精度、不同采样参数或不同 batch 基线之间比较，改变了问题；应分别报告模型分布变化和系统速度变化。

## 任务映射

方案筛查：先验证残差校正的正确性，再收集每轮已提交 token 数 L、draft/verification/其他耗时、horizon/树形、batch、目标数值设置及 EOS 截断。用整体 ΣL/ΣC 比較同配置 baseline，而不是按轮速度比取均值。若只有接受率，输出成本阈值或待测条件，不给“必然快几倍”的结论。
