# 推测采样：剩余质量校正与分布不变条件

## 问题触发

小模型、MTP 预测头或候选树一次给出多个 token，怎样判断它能否替代目标模型的随机采样？这里判断的是输出分布；greedy 一致、单次相同文本和评测分数相近分别是更窄或不同的命题。

## 精确结论（已知算法事实；本条重新推导）

固定一个已提交前缀 h，在同一有限 token 空间令 p(x) 为目标采样分布，q(x) 为实际提议分布，均非负且归一化。从 q 抽 X，以 a(X)=min(1,p(X)/q(X)) 接受；拒绝时从 r(x)=[p(x)−q(x)]₊/Z 重新抽样，其中 Z=Σx[p(x)−q(x)]₊。最终输出 Y 严格服从 p。

这里 p、q 是应用各自温度、top-k、top-p 等处理之后的实际分布，不是未经处理的 logits。目标 p 必须对应被比较的原始生成设置。若稀疏化、量化或额外截断使目标变成 p̃，校正至多恢复 p̃；相对 p̃ 的无损不说明相对原 dense 目标 p 无损，二者差异必须单独证明或测量。X 从 q 抽得，故实际访问的 q(X)>0；不要求 supp(p)⊆supp(q)。若 Z=0，则 p=q、必然接受，残差分支不可执行。

链式块必须按次序核验，接受最长合法前缀；第一次拒绝后从该处残差取一个 token 并丢弃后续草稿。全部接受时可再从正确前缀的目标分布取一个 bonus token。每一步的目标概率、提议概率和 KV/位置状态都必须对应同一个真实前缀；在这些条件下逐 token 的条件分布不变，因而有限输出序列的联合分布不变。

## 推导范围与边界

接受并输出 x 的质量是 q(x)a(x)=min(p(x),q(x))。拒绝概率为 1−Σx min(p(x),q(x))=Z，故拒绝后输出 x 的质量是 Zr(x)=[p(x)−q(x)]₊。两项之和恰为 p(x)。这是有限概率代数证明，不是模型实验或形式化验证。

这一论证只要求提议机制的实际条件分布已知且使用一致，不要求提议模型与目标模型架构相同。若 tokenizer 不同，须先给出落到同一输出空间的正确提议概率映射；不能直接比较无对应关系的 token ID。

数值实现仍须处理下溢、零分母、归一化、缓存回滚和随机数状态。实数分布等价不承诺相同 seed 产生逐字相同序列，也不承诺不同数值 kernel 的 bitwise 等价。相同 EOS/长度终止规则可作用于正确生成的序列；不要把块尾被截断的 token 计入已发出吞吐量。

## 算得出的正例

p=(3/5,3/10,1/10)，q=(1/5,1/2,3/10)。接受输出质量为 (1/5,3/10,1/10)，总接受率为 3/5；Z=2/5，r=(1,0,0)。补回残差后得到 (3/5,3/10,1/10)。即使 q=(1,0,0)，算法仍能产生 p 支撑中的其他 token；它们由拒绝分支补回。

## 失败与反例（本条构造）

- 同一例子中，若拒绝后直接抽 p，输出变为 (11/25,21/50,7/50)，不再是 p。是否碰巧通过少量样本不能修复概率恒等式。
- 若生成时总取 q 的 argmax，却仍用软 q 计算接受比，真实提议已变为点质量；原公式的前提被破坏。
- 对 p=(3/5,2/5)，始终选择最大概率 token 与目标 greedy 一致，却不保持随机采样 p。只有把目标本身定义成带固定 tie-break 的点质量时，greedy 验证才直接对应这一目标。
- 若第二位置的目标计算使用了候选树的兄弟节点或已拒绝前缀，得到的是另一个条件分布；树注意力的并行形状本身不是正确性证明。

## 树与 MTP 的合法使用边界

树、MTP 和特征预测描述候选如何生成，并不单独决定核验规则是否无损。可以将它们接到经过证明的校正器，或另外证明整个核验过程；不能从其名称推出任意 sampling 配置下的分布等价。

一个不同但合法的局部核验方式是确定性候选消元：在同一前缀下，按已定顺序考察不同 token c，当前剩余分布为 u；以 u(c) 接受 c，拒绝后把 c 的质量置零并归一化。把本次提议看成 q=δc，便得到上面的残差定理。候选耗尽后抽剩余分布。每次候选选择不得偷看本次接受所用的随机数，且沿树继续时仍须满足正确前缀条件。

例如 p=(3/5,3/10,1/10)，先考察 b 再 c：接受 b 的总质量为 3/10，拒绝 b 后接受 c 的总质量为 (7/10)(1/7)=1/10，最终 a 占 3/5。它不要求把候选树置信分数当成一个一次性 q 分布。

## 任务映射

审阅声称“无损推测加速”的方案时先列四项：目标分布、实际提议规律、拒绝补偿、前缀/缓存一致性。能明确映射到本定理才采用；只给 greedy 相同或某 benchmark 分数相同，标记随机分布命题尚未验证。无损与能否加速还要分别检查成本条目。
