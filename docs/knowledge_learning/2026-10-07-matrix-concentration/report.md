# 有界二阶矩集中与子空间校准：2026-10-07

本轮新增的可复用能力是：先区分二阶矩与中心协方差，审查样本独立性、事前范数界与固定采样量，再把有限样本谱误差传递为有条件的主子空间和查询分数误差证书。它不证明实际文档 token 独立，也不证明 indexer 的模型质量或速度提升。

## 数学条目与消费者

稳定 ID：`math.matrix-bernstein-covariance`，版本1，已纳入学科和问题结构索引及 `model-with-knowledge` 插件快照。沿用现有按需检索入口，不新增 Skill。

设事先固定的 n 个独立同分布向量满足几乎处处范数不超过 L，目标为 M=E[xxᵀ]。条目给出中心矩阵范数和矩阵方差的推导，以及

\[
\Pr(\|\widehat M-M\|\geq\varepsilon)
\leq 2d\exp\!\left[-\frac{n\varepsilon^2}{2L^2\|M\|+(2/3)L^2\varepsilon}\right].
\]

有可证明的确定性上界 B≥‖M‖ 时，用 a=log(2d/δ)、εₙ=√(2L²Ba/n)+2L²a/(3n)；未知时可取 B=L²。不可直接用观测范数或观测最大样本替代总体上界。非零均值时 M 不是中心协方差。

条目包含自足的秩一主子空间证明：在谱误差事件内，观测谱隙 ĝ>2εₙ 足以保证真实最大特征值简单，投影误差至多 εₙ/(ĝ−εₙ)，有界 q、k 的分数偏差再乘 ‖q‖‖k‖。该证书只控制校准基漂移，不包含截断、量化、粗筛丢失或完整 attention 输出误差。

具体迁移是独立有界合成校准向量的基估计；跨领域例子是相同单位、独立测量的电压传感器主轴。电压范数单位为 V，二阶矩/谱隙/误差为 V²，主角无量纲。时间相关测量、重复文档 token、事后选出的 token 均不能直接计为独立样本。

## 验证与拒用

[verify.py](verify.py) 的33项公开开发检查全部通过；[checks.json](checks.json) 保存运行环境、时间和数值。Fraction 精确有限恒等式及二项计数枚举用于检查中心化/方差；NumPy float64 用于谱隙和分数样例。它们不代替一般证明，也不是 Lean 验证、未见测试或真实物理实验。

| 合成检查 | 观测 | 上界/结果 |
|---|---:|---:|
| n=80、误差阈值0.25，精确有限尾概率 | 2.6414e−9 | 0.282996 |
| n=10000，二阶矩谱误差 | 0.0048 | 0.0298963 |
| 主轴投影误差 | 0.0055794 | 0.0435848 |
| 查询分数误差 | 0.0041141 | 0.0371111 |

拒用反例覆盖：复制一次抽样不能使误差随计数收敛；按方向选样会改变总体目标；常量向量二阶矩非零但中心协方差为零；未观测稀有大范数不能用观测最大值排除；谱隙不足不能认证唯一方向；样本对内部相关不等于样本对之间依赖。检查脚本验证的是这些数学结构和反例，未测模型是否实际拒用。

[queries.json](queries.json) 的4道不提示定理名问题在 files/SQLite 的原始 Top-3 均包含目标条目；它们是本轮编写并公开的开发题，不能再作为未见验收。21道旧开发题的原始平均 Top-3 recall 保持0.809524，现有候选上下文召回保持1；旧查询遗漏仍保留，不声称全部问题已解决。运行记录见 [retrieval.json](retrieval.json)、[baseline-retrieval.json](baseline-retrieval.json)、[regression.json](regression.json)。部分通用上下文包仍触及预算；针对本轮校准结构的实际使用单独限制为一条、自足核验，见 [knowledge-use.json](knowledge-use.json)。
