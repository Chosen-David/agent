# 本轮结果：小残差的应用与拒用条件

新增 `math.linear-solve-backward-error` v1，覆盖联合非结构化后向误差、残差到前向误差、可核验逆范数上界及线性评分的严格间隔。经典定义和条件已核对Higham教材章节及Betcke讲义；负号构造、逆界与下游查询推导在正文明确可复核。近期来源固定到2026-09-10的arXiv2609.12266v1，版本、哈希、发表状态和实际阅读页见sources.json，筛选结论见research.md。

## 真正增加的知识能力

面对“残差很小，解或排序是否可靠”，可先核对可逆性、范数、残差计算误差和逆算子界，再返回绝对误差或拒绝保证。确定的线性评分映射可把这个界传到排名；接地导纳网络可以传到有正确单位的电压误差。未接地系统、未被覆盖的数据误差、仅经验条件数及非线性任务不能直接应用。这是按需知识能力和结构检查，不是已验证的主AI质量提升。

学科覆盖新增 numerical-analysis / linear-algebra；问题结构新增 linear-solve / conditioning / residual-error-bound / grounded-network。既有索引器从条目元数据构建，两种后端均实际检索；插件知识快照已同步。没有新增Skill、常驻提示或生产求解规则。

## 实际验证

- verify.py：65项有限检查通过，以Fraction精确验证构造和界，另检查binary64舍入、取消、严格间隔、共同缩放、零右端及奇异反例；约1.1毫秒仅指该脚本的计算区间。人工一般证明核查不是Lean形式化验证。
- 反例：残差2×10⁻⁸、后向误差约2.22×10⁻⁹，解误差2且排名翻转；逆界给出的误差上界大于4，正确拒绝排名保证。
- 物理迁移：接地电路得到0.03V误差界并认证电压次序；未接地网络的零残差对应可任意平移的绝对电压，明确拒用可逆前提。
- 近期算法候选：SM在刻意构造的binary64输入返回错误分量，MSM恢复近似真值。零浮点残差仍有非零精确误差；内求解2次→3次，不声称性能优势或普遍稳定性，不修改生产行为。
- 4道公开、无定理名查询，两后端Recall@3=1，平均倒数排名=1。文件查询中位耗时约9.5ms，SQLite约5.4ms；不含语料装载，不是生产性能对照。检索命中不能证明模型理解了前提或拒用反例。
