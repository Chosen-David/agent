## 边界

Git 文件是权威知识，SQLite 是可重建索引。没有部署 QMD、PageIndex、Lean、远程模型服务、定时触发器或持久监督器。宿主无 tmux；该阻塞不影响本轮代码与 Prompt 交付。已提供的 Prompt 可由有权限的调度器执行，本轮用户只要求编写 Prompt。

5 条发布种子含来源核对、非形式化推导、例子与反例；发布标记不等于形式化证明。检索是词法/结构融合，没有密集语义向量或学习式重排。全库校验仍与语料大小线性相关。导入器处理本地带来源候选，不自动抓取未知许可内容；数学正确性与发布仍需维护者核验。
