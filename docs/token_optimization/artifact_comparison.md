# Self-contained artifact version comparison

For a review that needs both versions of a task brief or text artifact, pass two actual project-relative path/sha256 reference JSON files:

```powershell
python scripts/artifact_context.py --root ABSOLUTE_PROJECT_ROOT --before before-ref.json --after after-ref.json
```

`--full` keeps both complete texts explicitly. The default includes the complete old text in the **same output** and may represent the new version as one replacement of complete lines with their terminators. It selects that representation only if its complete JSON is smaller; otherwise it returns the full new text. It does not summarize, omit conditions, or depend on a persisted claim that the model still remembers a file. Both input files are read and their SHA-256 values checked; unsafe, stale, unknown or oversized input and output fail without truncation.

Consumers use `agent_runtime.artifact_context.restore_comparison(root, payload, before_ref, after_ref)` with their independently fixed project and references. It restores exact text/UTF-8 bytes, including CRLF, Unicode, deletion and new cancellation. Restoration checks transport identity, not current filesystem freshness or scientific usability. Existing current guide/instructions, cancellation, authorization and independent result gates still apply. A new task or dataset version must not be treated as unchanged just because its shared text is compressed. This is an explicit comparison entry, not automatic Codex history management.
