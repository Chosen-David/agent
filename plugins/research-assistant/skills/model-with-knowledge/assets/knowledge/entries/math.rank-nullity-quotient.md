# 向量空间、商空间与对偶查询的保真条件

稳定 ID：math.rank-nullity-quotient；语义版本1；核查日期2026-10-07。

## 对象、符号与前提
V,W 为有限维 F 向量空间，T:V→W 线性，查询 q∈V* 线性；代数对偶不默认欧氏内积。

## 基础定义与维数关系
向量空间的子空间对加法与标量乘法封闭；span 是有限线性组合的集合；独立表示零组合只能有零系数；基是独立且张成的列表。有限维基的长度一致，作为维数。对 U,W⊆V，dim(U+W)=dim U+dim W−dim(U∩W)：将交的基分别延拓为 U、W 的基，合并后删掉交的重复基。U+W 为直和 iff 交为0；每个向量的两部分分解此时唯一。矩阵行消元是左乘可逆初等矩阵，不改变核或 Ax=b 的可解性（rhs 要同时变）。

## 经典结论
dim V=dim ker T+dim im T；V/ker T≅im T。Ax=b 可解 iff b∈im A，解集 x₀+ker A。仅从 Tx 恢复所有 x 的 q(x) iff q 在 ker T 上为零，等价 q=ℓ∘T；矩阵坐标下 q 属于 T 的行空间。

## 证明思路与可复核推导
把 ker T 的基延拓成 V 的基；补充基的像线性独立并张成 im T。映射 [x]→Tx 因核为零而良定义且双射。若查询保真则核内 x 与0编码相同所以 q(x)=0；反之定义 ℓ(Tx)=q(x)，对 im T 良定义，再延拓到 W。

## 正例与边界
T(x,y,z)=(x+y,z)，秩2核 span(1,−1,0)；q=x+y 可恢复，q=x 不可恢复。零映射的核是全部 V，只有零查询能无损恢复。

## 误用反例与拒用条件
降维不保证任意后续点积、非线性语义查询或排序保真。丢失核方向时增加 token 摘要不能自动恢复；需明确查询族或误差界。无限维时本条有限维计数不能照搬。

## 问题结构与迁移
Agent 通信中的精确线性摘要是一种商映射；仅在消费者查询族 annihilates kernel 时可证保真。自然语言摘要只有类比，不纳入生产保证。
