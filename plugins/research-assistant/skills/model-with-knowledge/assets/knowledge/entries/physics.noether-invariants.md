# 守恒量作为模型检查

## 精确结论与推导范围
记 pi=∂L/∂q_dot_i。若时间不变的无穷小点变换 δq=εξ(q) 使 δL=0，则沿 Euler–Lagrange 解，J=Σpi ξi 守恒。
链式法则给 δL=Σ(∂L/∂qi)ξi+Σpi dξi/dt。用 p_dot_i=∂L/∂qi，右侧正是 dJ/dt，故为零。

另令 H=Σpi q_dot_i−L，直接求导并用方程得 dH/dt=−∂L/∂t。L 自治时 H 守恒。对 L=T−V、T 为速度二次型且 V 不依赖速度的常见机械系统，H=T+V；一般拉格朗日量不能无条件这样认定。
这里不给出含时间变化/全导数边界项的最一般 Noether 公式，也未运行形式化证明器。

## 例子与失败
单位质量和弹簧常数的谐振子，L=(v²−q²)/2，q_dot=v、v_dot=−q，使 H=(q²+v²)/2 的导数为零。
若改为 v_dot=−q−γv，机械能变化率为 −γv²，不能把耗散错误标成实现 bug。
离散显式 Euler：q'=q+h v、v'=v−h q，得到 H'=(1+h²)H。连续方程守恒不意味着任意离散器精确守恒。

## 任务映射
可用于物理模拟回归、发现遗漏外力、区别模型守恒与积分误差。对 Agent 的资源/预算不变量只能提出需要证明的工程映射：若没有真实作用量、连续对称和演化方程，就不能引用 Noether 宣称 token 或信息守恒。有限标签置换也不自动给连续守恒量。
