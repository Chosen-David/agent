# 内积误差界

## 命题与符号
实向量 u,v 满足 |uᵀv| ≤ ‖u‖₂‖v‖₂。因此固定 q 时，
|qᵀk − qᵀk_hat| ≤ ‖q‖₂‖k−k_hat‖₂。
来源支持基础不等式；分数误差是本条直接推论。

## 推导
v=0 时显然。否则取 t=(uᵀv)/‖v‖₂²，由 ‖u−tv‖₂²≥0 得
‖u‖₂²−(uᵀv)²/‖v‖₂²≥0。取平方根，再令 u=q、v=k−k_hat。

## 实例
q=(3,4)，k−k_hat=(0.06,0.08)，内积误差 0.5，范数乘积也是 0.5。

## 误用与验证
平均键误差不能替代每个键的上界。例：q=(1)，两个键误差为 0 和 2，
均值为 1，却有分数误差 2。查询也变化时用分解
qᵀk−q_hatᵀk_hat=(q−q_hat)ᵀk+q_hatᵀ(k−k_hat)，分别取界。
范数界不自动保证排序、softmax 输出或模型任务精度。
