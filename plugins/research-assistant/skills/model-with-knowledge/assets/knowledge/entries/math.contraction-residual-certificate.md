# 收缩迭代的残差误差证书

稳定ID：`math.contraction-residual-certificate`，版本1。经典定理与本文推导分开标注；知识可发布，生产停止策略未验证。

## 对象、条件与经典结论

非空完备度量空间 (X,d)，自映射 G:X→X，存在统一 q∈[0,1) 使 d(Gx,Gy)≤q d(x,y)。则存在唯一不动点 x*，精确迭代 x_(k+1)=Gx_k 收敛。误差 ≤ q^k d(x_1,x_0)/(1−q)，k≥0；对 k≥1，误差 ≤ q d(x_k,x_(k−1))/(1−q)。q=0 时G恒定，一步精确；零次上界直接使用残差公式，避免0^0记法。

来源：Voutsadakis，Introduction to Functional Analysis，May2023，pp7–11，p10误差推论。Bindel CS4220，2026-03-27，固定点与线性化讲义。只读这些相关章节，不声称全教材审查。

## 可复核证明与本条目推导

经典证明：相邻距离≤q^k d(x_1,x_0)，有限尾和≤q^k d(x_1,x_0)/(1−q)，所以Cauchy；完备性给极限，自映射与Lipschitz连续给Gx*=x*。两个不动点距离≤q乘自身，故唯一。取尾和极限得先验界和后验界。

本条目推导：任意x∈X的残差 r=d(x,Gx)，由 d(x,x*)≤r+q d(x,x*) 得当前误差≤r/(1−q)。精确新点y=Gx，误差≤qr/(1−q)。

范数空间中的不精确oracle满足 ||G̃x−Gx||≤η，η≥0是已认证上界。计算残差 r̂=||x−G̃x||。当前误差≤(r̂+η)/(1−q)。返回y=G̃x时：先由 ||x−x*||≤r̂+||y−x*||，再由 ||y−x*||≤q||x−x*||+η，合并得到新点误差≤(q r̂+η)/(1−q)。它不同于当前点界。浮点计算r̂自身的不确定性应增加到r̂的上界，不能忽略。

重复不精确更新在不变域中：e_k≤q^k e_0+η(1−q^k)/(1−q)，通过递推归纳；误差平台上界η/(1−q)不等于误差必达该值，也不证明随机oracle具有确定性η。

## 正例、边界与误用

1. Gx=.99x+.01，x*=1，x0=0。第一步.01小于.02但返回点误差.99；证书也为.99。达到.02误差需390步。小步长在q接近1时尤其误导。
2. Gx=.9x+1，真解10；G̃x=Gx−.1，在x=9计算残差0，真实误差1，η=.1的证书为1。不能宣称.01精度。
3. q=1时恒等映射有多个不动点，不可除以1−q。开域(0,∞)上的Gx=x/2不是完备域，没有域内不动点；[0,1]上的x/2+1不自映射，收缩不够。
4. A=[[.5,10],[0,.5]]，谱半径.5，但无穷范数算子界10.5；e0=(0,1)→(10,.5)，误差增大。不能将谱半径代入当前范数的逐步界。自推导：加权范数max(|x1|/40,|x2|)诱导行界max(.5+10/40,.5)=.75，故可用q=.75；换回普通无穷范数必须乘40，上界可能很松。
5. 几个观测比率不提供全局q。凸域上处处导数算子范数≤q可用线段积分证明Lipschitz；非凸域不能省略连线条件。先验证域不变再使用导数界。
