# 执行与验收补充

这些步骤细化已有职责；不改变用户目标、权限或外部 API。按本次任务需要应用，不要求简单问答生成全套文件。

1. 先冻结 PDF hash 和物理页数，再渲染；逐页打开图像，读正文、图、表和图注，记录每页实际新增信息。页码、截图和发现绑定同一 hash。不能用作者源文件补全读者看不到的内容。

2. 渲染状态与阅读状态分离：rendered 不推出 opened，opened 不推出 read_complete。空白页、附录、参考文献也逐页确认；无法查看时输出 partial_review 和未读页，不把 OCR 错误直接当版面缺陷。

3. 每个疑点有页/锚点、观察、影响、核验方式；排版与科学问题分开。改稿后新 hash 对应新账本，旧图片不能关闭新版本问题。工具仅检查覆盖和版本声明，不能自动证明视觉审读真实发生。

复杂交接附实际输入版本、产物路径、已执行检查、限制与下一负责人。外部后端发现不等于可运行或已授权；没有后端时用当前工具完成有界任务。

知识需求与交接按 [知识接入契约](knowledge_access_workflow.md) 执行；保留实际查询/前提核对证据及完整 knowledge_refs，无需求时注明原因。
